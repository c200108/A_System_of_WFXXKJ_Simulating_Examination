# 仿真操作题

操作题原来只能老师一份份看着给分，一个班五十份、一份三道题，一场考试批下来
两三个小时。仿真操作题让学生**在网页里把操作真做一遍**，交卷后按检查点自动判分。

支持四类：

| 题型 | 学生看到什么 | 能考什么 |
|---|---|---|
| **Windows 操作** | XP 桌面：任务栏、开始菜单、资源管理器 | 新建 / 改名 / 移动 / 复制 / 删除 / 回收站 / 只读隐藏属性 / 记事本写内容，二十多种文件类型 |
| **WPS 文字** | 照着 WPS 界面做的排版环境 | 字体字号字形颜色、突出显示、底纹、边框、上下标、删除线、项目符号编号、五种对齐、缩进、行距、段前段后、样式、页边距、纸张方向、页眉页脚、分栏、查找替换、段落移动 |
| **网页编程** | 代码编辑器（HTML + CSS）+ 实时预览 | 标签、属性、标题、**样式**，服务端解析成树来判 |
| **AI 工具** | 一个 AI 对话界面 | 会不会把题目要求清楚地提给 AI 工具。**不用老师出检查点** |

---

## 一、出一道题（三步）

### 第 1 步：建仿真任务

**题库 → 仿真操作题 → 新建**，选题型。然后：

1. **① 布置环境** —— 把学生打开时该看到的样子摆好（建几个文件夹、放一段范文、
   写好初始代码），点「把当前状态设为初始环境」
2. **② 做标准答案** —— 从初始环境开始，**按题目要求做一遍**，点「生成检查点」

系统会把前后差异翻译成一条条检查点：

```
① 新建文件夹「作业」        2 分
② 新建文件「冬梦.txt」      2 分
③ 「冬梦.txt」里写上内容     2 分
```

改改描述和分值，点「保存」。**不用写 JSON。**

> 存之前按一次「试判一下」：按答案做完应该是满分，什么都不做应该 0 分。
> 检查点写错了（比如路径少一层）在这里就能发现，不用等考完看见全班 0 分。

### 第 2 步：把题挂上去

**题库 → 题库管理**，编辑（或新增）一道**操作题**，题型选「操作题」之后会多出
一个「仿真任务」下拉，选中刚建的那个，保存。

题干照旧写清楚要求（第几问做什么），**题干是学生唯一能看到的说明**。

### 第 3 步：照常组卷、发考试

组卷时这道题和普通操作题没有区别。学生答题页上，这道题会显示成一个仿真窗口。

### AI 工具题只有一步

这类题（题干形如「D:\EXAM生成式人工智能，请使用给定的 AI 工具完成要求」）**不用走上面的两步**：
新建时选「AI 工具」，填个工具名（通义千问 / 文心一言 / DeepSeek…）和开场白，存。

- 不用布置环境，不用做标准答案，**不用出检查点**
- 判分时按**题干**现算：① 提交过提问　② 提问内容覆盖题目要求
- 所以**题干要把要求写清楚** —— 它既是给学生看的，也是判分的比对基准

> 对话里的回复是本地模板拼的，不联网调用真实大模型。界面上也写明了这一点。
> 三个理由：考试环境不该往外发请求（一个机房五十台机器同时问，出口先挂）；
> 真模型的回复不可控；这类题考的是"会不会把需求说清楚"，不是模型答得好不好。
> 要接真模型，把 `SimAi.vue` 里的 `reply()` 换成调后端接口即可，判分那边一个字不用动。

## 二、判分口径

### 判终态，不判步骤

新建文件夹可以右键菜单、可以菜单栏、可以快捷键；设置居中可以点工具栏、可以
Ctrl+E、可以右键段落对话框。**按"点了哪几下"判分会把做对的学生判错**，所以
判的是**最终状态**——和真考查结果文件是一个道理。

学生的操作日志照样存着（最近 200 步），但只用于事后回放和申诉，不参与判分。

### 部分给分

每个检查点一档分，做对几问得几问的分。

### 分值按卷面折算

检查点的满分是出题时定的（比如四小问各 2 分 = 8 分），而卷面分值是组卷时按难度
分摊的（这道题可能只占 7 分），两者对不上是常态。判分时按比例折算，
**不会出现一道 7 分的题判出 8 分**。

### 老师有最终决定权

机器判出来的分是**预填**到成绩页的，老师在「考试 → 成绩 → 阅卷」里能改。
成绩页上每道仿真题会列出每一问过没过、没过是因为什么：

```
✓ 在「会徽」里新建文本文件「冬梦.txt」
✕ 文件里写上指定内容（内容里没有「北京冬奥」）
```

机器判错了老师能救 —— 不留人工出口的判分系统，出一次错就没人再信它。

### 只对「有分值的卷子」生效

2.4.0 之后按大题组的卷子每题都有分值，仿真题才谈得上给几分。更早的老卷子不设
分值、按正确率折百分制，那种卷子里的操作题仍然走人工评阅。

## 三、检查点规则（要手改时看这里）

出题台生成的检查点，下面那行灰字就是实际判分的规则。一般不用动，真要调
（比如把「等于」改成「包含」）照着这里改。

### Windows 操作

| 规则 | 意思 |
|---|---|
| `{"op":"exists","path":"C:/EXAM/a.txt","is":"file"}` | 这个路径存在，且是文件（`"dir"` = 文件夹） |
| `{"op":"missing","path":"C:/EXAM/旧.txt"}` | 这个路径不存在了（考「删除」） |
| `{"op":"in_recycle","path":"C:/EXAM/旧.txt"}` | 在回收站里 |
| `{"op":"content","path":"C:/EXAM/a.txt","has":"冬奥"}` | 文件内容里有这几个字（`"equals"` = 完全相同） |
| `{"op":"attr","path":"C:/EXAM/a.txt","readonly":true}` | 只读 / 隐藏属性（`"hidden"`） |
| `{"op":"count","path":"C:/EXAM/作业","equals":3}` | 这个文件夹下正好有 3 项 |

路径写 `C:/EXAM` 还是 `C:\EXAM`、结尾带不带斜杠，都当成同一个地方。
**文件名的大小写要对**——中考里大小写错了同样算错。

### WPS 文字

| 规则 | 意思 |
|---|---|
| `{"op":"para","at":0,"font":"楷体","size":"二号","bold":true,"align":"center"}` | 第 1 段（从 0 数）的格式 |
| `{"op":"para","at":{"has":"深圳男孩"},"indent":2}` | **含这几个字的那一段**的格式 |
| `{"op":"text","absent":"10后","present":"00后"}` | 全文没有前者、有后者（考查找替换） |
| `{"op":"order","first":"…","last":"…"}` | 第一段 / 最后一段是哪一段（考「移动到文章末尾」） |
| `{"op":"page","left":2.5,"top":2,"orient":"portrait"}` | 页边距（厘米）、纸张方向 |
| `{"op":"header","equals":"春天"}` | 页眉（`"footer"` 同理，`"has"` = 包含） |
| `{"op":"columns","equals":2}` | 分了几栏 |

`para` 里可用的键：`font size bold italic underline strike sup sub color highlight
shading border bullet style align indent line before after`。
`bullet` 取 `none/dot/number`，`style` 取 `正文/标题1/标题2/标题3`。
`align` 取 `left/center/right/justify`；`line` 写 `{"type":"fixed","value":22}`
（`fixed` 固定值磅、`multiple` 多倍、`least` 最小值）。

字号写「二号」还是写 `22` 都认。

**按内容找段落（`at: {"has": "…"}`）比按序号可靠**：学生要是在前面插了一段，
段落序号就变了，按序号判会冤枉人。出题台生成的检查点默认就用按内容找。

### 网页编程

| 规则 | 意思 |
|---|---|
| `{"op":"css","selector":"h1","prop":"color","equals":"red"}` | **样式**：写在 style.css、`<style>` 块、行内 `style=""` 里都算 |
| `{"op":"sel","selector":"a[href]","min":1}` | 至少有 1 个带 href 的 a 标签 |
| `{"op":"sel","selector":"body h1.t","min":1}` | 支持后代（空格）、`#id`、`.类`、`[属性]`、`[属性=值]` |
| `{"op":"attr","selector":"img","name":"src","equals":"logo.png"}` | img 的 src 等于（`"has"` = 包含） |
| `{"op":"title","equals":"我的主页"}` | 网页标题 |
| `{"op":"raw","has":"<marquee"}` | 源码里有这一串（兜底用，尽量用上面几种） |

判的是**解析出来的标签树**，所以学生的缩进、单引号双引号、属性顺序都不影响
得分；忘了写 `</p>` 也照常能判。颜色 `red`、`#f00`、`#FF0000` 当成同一个值。

### AI 工具题

老师不用写，但要知道它在判什么：

| 规则 | 意思 |
|---|---|
| `{"op":"asked","min_len":8}` | 提交过一条够长的提问 |
| `{"op":"covers","text":"题目要求","ratio":0.5}` | 提问覆盖了要求的多少（按相邻两字的组合算） |
| `{"op":"turns","min":1}` | 至少提问了几次 |

覆盖度按**两字组合**算而不是按单字：单字太容易撞（「的」「一」到处都是），
两字组合能区分"照着要求提问"和"随便打两个字"。**AI 回的内容不计分** ——
那不该由学生负责，也没法客观判。

## 三点五、Windows 题里的文件类型

「新建」菜单能建：文件夹、文本文档、Word 文档、WPS 文字文档、BMP 图像、HTML、ZIP。
双击的行为按扩展名走：

| 类别 | 扩展名 | 双击之后 |
|---|---|---|
| 文本 | txt log html css js | 记事本，**能改内容**（判分可以查内容） |
| 文档 | doc docx wps pdf ppt pptx xls xlsx et | 只读的文档查看器 |
| 图像 | jpg jpeg png gif bmp | 图片查看器（画的占位图，不加载真实图片） |
| 音视频 | mp3 wav flac mp4 avi wmv | 播放器界面，不实际播放 |
| 压缩包 | zip rar 7z | 列出里面有什么 |
| 数据库 | mdb accdb | 占位界面 |
| 程序 | exe msi bat | 提示「考试环境中不运行程序」 |

要加新扩展名，改 `frontend/src/components/sim/fileTypes.js` 一个地方就够，
图标、"新建"菜单、双击行为都跟着走。

## 三点六、一个机房同时开考

五十到一百台机器同时用，做过这些：

| 做法 | 效果 |
|---|---|
| nginx 开 gzip | 首屏体积压到三成左右 |
| 带指纹的静态资源缓存一年，index.html 不缓存 | 第二次开考几乎不用下载；发新版本也不会读到旧的 |
| 第三方库拆成单独的块 | 改业务代码不会让库的缓存失效 |
| 四个仿真器按需加载 | 做客观题的学生一个字节都不下载；一个仿真器 20~30 KB |
| 图标按需引入 | 原来一千多个图标全打进主包，实际只用两个，砍掉省 150 KB |
| 后端默认 2 个工作进程 | 交卷高峰不排长队。核少就在 `.env` 里写 `WEB_WORKERS=1` |
| 题面和检查点有体积上限 | 题面是**每个学生下载一份**的东西，不让它被撑大 |

出题时也请留意：**题面环境越小越好**。WPS 题的范文别整篇几千字粘进来，
截取要考的那几段就够 —— 它会乘以考试人数变成流量。

## 四、已知的限制

**仿真不等于真机。** 图标、菜单位置按真软件还原，但手感有差距；中考是真机考，
所以这东西的定位是**平时练和形成性评价**，替代不了真机模拟考。

**WPS 的格式挂在段落上。** 真 Word 可以同一段里半句楷体半句宋体，这里做不到 ——
中考的 WPS 题九成是「把某段设成……」，按段落记够用，判分也写得清楚。要考
「把某几个字设成红色」得先把文档模型升级成字符游程。

**网页题不跑 JS。** 预览用的 iframe 关掉了脚本 —— 那里跑的是学生写的代码，
让它执行 JS 等于在考试页上开了个口子。所以网页题只考结构和样式。

**删掉仿真任务不会删题。** 挂着它的题会退回「老师人工评阅」，已经考完的成绩
一分不变。
