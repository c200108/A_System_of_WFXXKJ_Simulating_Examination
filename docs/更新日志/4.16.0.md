# 学生端 4.16.0 —— 签到按机器号自动认座

发布：2026-11-24（和服务端 2.26.0 同一期）

- 问「有没有签到」时带上电脑名（`platform.node()`）和连教师端那块网卡的内网 IP（UDP connect 取，不发包）。
- 服务端认出座号直接签上：不弹选择框，右下角绿条提示 4 秒「已按这台电脑的座号自动签到：C14」。
- 认出来了但签不上（同一个座号被另一台认出的电脑签了）：签到框只给这一个座号，红字写原因。
- 绑座模式：弹「这台电脑的座号」框，不锁窗口、能关；关了这一轮不再弹。

- 签到最后 1 分钟还没签：签到框外框变红、标题改成「签到快结束了，请马上签到！」、提到最前。
- 在别的电脑签过、换到这台：签到框说明在哪个座位签过；已经签满两台：不锁窗口，右下角红条提示。

详细说明见 [2.26.0.md](2.26.0.md)。
