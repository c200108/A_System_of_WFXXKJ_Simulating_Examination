# 4.5.0 —— 认得出的图标，跑得动的老机器，快一倍的连接

发布：2026-09-21　｜　配套：仿真环境 3.2.x、网页端 2.8.1

这一版全在学生桌面端：换校徽图标、补齐 Win7 支持、把"加载慢"真正查清楚。

---

## 一、图标换成校徽

原来是 PyInstaller 的默认图标 —— 机房桌面上几十台机器，学生找不到该点哪个。

现在用学校那枚**已经融合了信息科技元素**的徽章：电路走线、芯片、二进制、
`code`、`01` 都在里面，配色是原来的金底红字。脚本不往上加任何东西 ——
徽章本身已经把"这所学校 + 信息科技"说完了，再套一圈只会打架。

脚本只做三件事：切成圆形、切掉圆外的白边（不切的话贴在深色任务栏上是个白方块）、
按尺寸出 ico。**不抠底色**：金底是设计的一部分，抠了只剩红线条飘在白底上。

### 小尺寸另画一版

16×16 的任务栏图标只有 256 个像素，徽章上的楼、英文、二进制全糊成一团 ——
48×48 也一样糊。所以：

| 尺寸 | 画什么 | 出现在哪 |
|---|---|---|
| 16 / 24 / 32 / 48 | 金盘 + 红环 + 芯片 | 任务栏、Alt+Tab、资源管理器中等图标 |
| 64 / 128 / 256 | 校徽原样 | 大图标、属性页、桌面快捷方式 |

简笔版的配色跟着校徽走（金底红字），所以缩到 16 像素也还是"同一家的东西"。
ico 本来就允许每个尺寸放不一样的图，用上它而已。

换徽章不用改代码：`desktop/图标/校徽.png` 换一张，跑一次 `制作图标.py`。

**窗口左上角那个图标是单独一件事**：exe 的图标是打包时钉进去的，Tk 窗口的图标
要在运行时设，不设就是 Tk 那根羽毛。所以 ico 也随包带一份，装机自检会报
「√ 窗口图标带上了」——"源码下好好的、打包之后找不到"是附带文件最典型的毛病。

## 二、32 位和 64 位两版并存

Win7 时代的机房里 32 位机器不少，而 64 位的 exe 在 32 位 Windows 上**根本起不来**。

现在两版一起出，位数写在文件名里：

```
考试客户端-32位@111.170.33.3_3315.exe      8.5 MB   32 位和 64 位 Windows 都能跑
考试客户端-64位@111.170.33.3_3315.exe      9.4 MB   只能跑 64 位 Windows
```

不确定机房是什么机器，就统一发 32 位那份。

位数标在 `@` **前面**是有讲究的：客户端解析地址只认 `@` 之后那一段，标在前面
两边才不会打架。打包脚本也改了 —— 打一版不再删掉另一版（原来每次打包都会把
「发布」清空）。

## 三、Win7 的字体里没有那些符号

界面上原来用了 🏠 📝 ⌨ ✓ ✗ ⚠ —— 在自己的 Win10/11 上看都正常，**Win7 上是一个个
空方框**：那些字符要 Segoe UI Emoji，而 Win7 没有这个字体。这种问题在开发机上
永远看不见，只在考场上出现。

判据用得上现成的：**能编进 GBK 的字符，任何中文 Windows 的字体都有字形**。
于是全换成 GBK 里有的：

```
🏠 📝 ⌨  →  ◎ ◆ ★       ✓ → √      ✗ → ×      ⚠ → ※      ⟳ 刷新 → 刷 新
```

并且加了一条测试守着（`tests/test_win7_glyphs.py`）：源码里出现 GBK 装不下的
字符就挂。以后谁顺手换个好看的 emoji，本机上看不出问题，测试会拦下来。

装机自检报告也改成 **GBK 落盘** —— 考场机器是中文 Windows，记事本双击打开
UTF-8 的中文 txt 是一屏乱码（考试记录 CSV 早就是 GBK，这回口径统一了）。

## 四、"加载慢"：连接根本没复用

学生报"刷新、打开考试都要等一下"。**量出来的**：

```
TCP 建连                       约 35 ms
一次最轻的接口调用（新连接）   60 ~ 95 ms      ← 握手 + 一个来回
同一条连接上再发一次           33 ms          ← 只剩一个来回
```

上一版加过一个 `Connection: keep-alive` 头就以为复用上了 —— **没有**：
urllib 每次 `urlopen` 都新建一个 `HTTPConnection`，头写得再好也照样重新握手。
加了头的 urllib 实测仍然 61~93 ms，和没加一样。

现在自己攥着连接（`http.client.HTTPConnection` 按 主机+端口 存着），实测：

| | 改之前 | 改之后 |
|---|---|---|
| 第一次调用 | 61~93 ms | 69 ms（要握手） |
| 之后每一次 | 61~93 ms | **33 ms** |

**GET 才复用，POST 一律新连接。** 池子里的连接可能已经被服务器按 keep-alive
超时悄悄关掉了，发出去才发现 —— 这时重发一次对 GET 是安全的，对 POST 不行：
交卷那一下要是服务器已经收到、只是回程断了，重发就成了交两次卷。多花一次握手，
换交卷这件事不出岔子。

## 验证

- 后端 **443 passed**，桌面端 **143 passed**（新增字体规则 10 条、两版共存 1 条）
- 32 位和 64 位两版**都**：自检通过、连上线上教师端、单独拷进空文件夹能跑、
  跑完不留文件、内嵌 7 个尺寸的图标
- 源码在 32 位和 64 位的 Python 3.8.10 上各跑了一遍：导入、Tk 建窗、HTTP、快照、
  压缩包，以及八屏界面全部建得出来（Tk 8.6.9）
- 连接复用的数字是用客户端自己的 `api` 模块连线上服务器量的，不是估的

## 升级注意

1. **两个 exe 都要重打并分发**。不确定机房是什么机器就统一发 32 位那份。
2. 线上教师端**还是 4.3 时期的版本**：实测 `/api/student/exams/{id}/review`
   返回 404。4.4 的「查看」按钮要等后端更新之后才有用 —— 后端不更新的话，
   学生点「查看」会看到一句"服务器拒绝了（404）"。**先更新后端，再发 exe。**
3. 换校徽：把新图存成 `desktop/图标/校徽.png`，跑
   `python 图标/制作图标.py`，再重打 exe。
