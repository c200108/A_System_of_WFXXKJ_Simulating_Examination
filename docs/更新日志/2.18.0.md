# 服务端 2.18.0 —— 网页上备份还原、一键更新

发布：2026-11-04

## 新增

系统管理员（部署时 `.env` 里 `ADMIN_USERNAME` 的那个账号）的「我的账号」里多了「数据备份与系统更新」：

- **导出数据**：直接下载 `exam-data-时间.zip`，里面是完整的 exam-data（数据表、配图、config.yaml、settings.env、清单），不含口令；和 `scripts/data-export.sh` 导出的格式一样，两边互通。
- **导入数据**：上传 exam-data 压缩包 → 体检（结构对不对、路径安不安全）→ 试算（tools.import_data，不写库）→ 服务器上跑 `data-import.sh`（先存回滚点）→ 重建后端、前端容器。期间网站可能有一段时间打不开。
- **教师端一键更新**：
  - 途径一：服务器从 GitHub 下载 main 压缩包（宿主机配了 GitHub 加速就顺着用）；
  - 途径二：上传 main 压缩包；
  - 两种都在压缩包所在目录执行 `unzip -p <zip> '*/scripts/update-from-zip.sh' > u.sh` 和 `bash u.sh <zip>`，**压缩包文件名按实际的来，不写死**。
- 导入、更新都要再输一次登录密码；一次只能做一件；进度和完整日志实时显示，升级时后端重启那一会儿页面自动等它回来。

## 主机助手

重建容器、跑升级脚本只能在宿主机上做。`scripts/host-agent-install.sh` 装两个 systemd 单元：`exam-host-agent.path` 盯着 `data/host-jobs/queue/`，有单子就拉起 `exam-host-agent.service` 跑 `scripts/host-agent.sh`。只认 import / update-github / update-zip 三种动作。`deploy.sh`、`update-from-zip.sh` 跑完自动装；没装时网页上显示安装命令。
