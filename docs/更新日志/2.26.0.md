# 服务端 2.26.0 —— 签到按机器号自动认座

发布：2026-11-24（和学生端 4.16.0 同一期）

## 解决什么问题

2.24.0 的课堂签到让学生从下拉框里自己选座号。有学生乱选、占掉别人的座号，后到的同学只能找老师。
机房里其实「这台电脑是哪个座位」是固定的：联想云教室的机房电脑名就是 `C09-COMPUTE-C14`，最后一段
C14 正是桌面浮条上显示的座号。但别的学校的电脑名不一定这么起，所以做成三层：

1. **认座规则**（管理员在「认座设置」里选，全校一份）：
   - `host_tail` 电脑名最后一段（按 `-`、`_`、`.`、空格切）就是座号；
   - `host_num` 电脑名末尾数字 − 偏移 = 第几个座位；
   - `ip_num` 内网 IP 末段 − 偏移 = 第几个座位；
   - `pick` 不认，学生自己选（默认，和 2.24.0 一样）。
   「第几个座位」按座号排：先字母后数字（A1、A2…A15、B1…），不按表格里摆的位置。
2. **绑座**（seat_bindings）：老师开绑座模式，每台学生机登录后选一次座号，存服务器（机房有还原卡，存学生机上
   重启就没了），按学生端设备号（机器名 + 网卡算的 X-Device-Id）认。绑定优先于规则。
3. 两样都认不出来的电脑照旧下拉框选。

## 怎么做的

- 学生端每 5 秒问一次 `/api/student/checkin`，4.16.0 起带上 `host`、`lan_ip`。服务端认得出座号就在这一问里
  **直接签上**（`signed.how = auto / bind`），不需要学生点任何东西。
- 认得出座号的电脑不许借 POST 签别的座号（409「这台电脑是 C14 号座位，只能签 C14」）。
- **座号认主人**：auto / bind 认出的座号已经被一个 `pick`（自己选）的占着，就把那条删掉、表里姓名清掉、换成
  真正的主人；被挤掉的同学下一问 `signed` 变回空，签到框重新弹出。两台电脑认出同一个座号（重名、规则不对），
  后来的签不上，`auto.error` 告诉学生找老师。
- 老师撤销：`DELETE /api/classes/{cid}/checkins/{kid}/entries/{eid}`。
- 预览：`/api/checkin-seat/preview` 拿 client_online 里最近 2 小时有心跳的电脑（按设备号去重）按「还没保存的」
  规则算一遍，同一个座号对上多台的标红。保存前先看清楚。
- 内网 IP 由学生端自己报：线上服务器在 nginx 后面，看到的是机房出口 IP，没法按 IP 认。
- 老师网页的签到进度版本号多加了一项（签到记录 id 之和），挤掉 / 撤销时人数不变也能触发表格重读。

## 升级注意

- 数据库迁移 0029：新表 seat_bindings，checkin_entries 加 how / host，client_online 加 host / lan_ip。启动时自动跑。
- 认座规则默认 `pick`，升级后行为和以前一样，管理员去「认座设置」里选了才生效。
- 老学生端（4.15.x）不报电脑名，认座规则对它不起作用（绑座要新学生端），照旧下拉框选。
