# 学生端 4.11.0 —— 姓名登录版先选班级、交卷门槛

发布：2026-10-09（同期平台 2.14.0，详见 [2.14.0.md](2.14.0.md)）

- **姓名登录版**登录页多一栏「班级」下拉（连上教师端后取班级列表，记住上次选的），下一栏照旧填**中文姓名**，
  初始密码 123456；卡片下面写明「班里有同学和你重名的，账号改填学号」。这一栏也认学号。
  打包开关仍是 `build.py --name-login`，文件名带「姓名登录」，Release 附件名 `name-login-*`。
- 离线开考按考试包名单里的「班级 + 姓名」找人（`roster_by_name`），连不上教师端时班级下拉从名单里补。
- **交卷门槛**：考试时间过了三分之二、并且答完三分之二的题才放行「交卷」（`ExamFrame.gate_reason`），不够时弹窗
  说还差几题、还要等多久，页脚一直提示「答满 N 题、并且开考 M 分钟后才能交卷」。时间到自动交卷不经过门槛。
  断电续考时已考的时间从草稿里接着算。

（起草时这一版曾改成「拼音登录版」，账号填姓名拼音全拼；发布前改回中文姓名，拼音整个去掉了。）

## 验证

`tests/test_ui.py`：姓名登录版（登录页文案和班级栏、姓名 + 123456、错密码、要先选班级、重名按班级分开、改密码、
离线按班级 + 姓名找人）、离线名单找人规则、交卷门槛（三分之二取整、时间和题数都够才放行、时间到照样自动交）。
桌面端全部测试通过。

## 升级注意

服务端要先升到 2.14.0（登录页的班级下拉接口）。4.10.0 的姓名登录版 exe 连 2.14.0 照样能登（没有班级栏，全校按姓名找，重名改填学号）。
