# 学生端 4.11.0 —— 拼音登录版、交卷门槛

发布：2026-10-09（同期平台 2.14.0，详见 [2.14.0.md](2.14.0.md)）

- 「姓名登录版」改成**拼音登录版**：登录页多一栏「班级」下拉（连上教师端后取班级列表，记住上次选的），
  下一栏「姓名拼音」，提示「全拼，如 zhangsan」；卡片下面写明「班里有同学和你拼音一样的，账号改填学号 · ü 打 v」。
  这一栏也认学号和中文姓名。
  打包开关仍是 `build.py --name-login`，文件名里的「姓名登录」换成「拼音登录」，Release 附件名 `pinyin-login-*`。
- 离线开考按考试包名单里的「班级 + 拼音」找人（`roster_by_pinyin`），连不上教师端时班级下拉从名单里补；
  老的考试包没有拼音，照旧按中文姓名找。
- **交卷门槛**：考试时间过了三分之二、并且答完三分之二的题才放行「交卷」（`ExamFrame.gate_reason`），不够时弹窗
  说还差几题、还要等多久，页脚一直提示「答满 N 题、并且开考 M 分钟后才能交卷」。时间到自动交卷不经过门槛。
  断电续考时已考的时间从草稿里接着算。

## 验证

`tests/test_ui.py`：拼音登录版 8 条（登录页文案和班级栏、拼音 + 123456、错密码、要先选班级、重名按班级分开、改密码、
中文姓名还认、离线按拼音找人）、离线名单找人规则 1 条、交卷门槛 3 条（三分之二取整、时间和题数都够才放行、时间到照样自动交）。
桌面端全部测试通过。

## 升级注意

服务端要先升到 2.14.0（学生要有拼音）。4.10.0 的姓名登录版 exe 连 2.14.0 也能登（没有班级栏，拼音全校不重的才认，重了改填学号）。
