# 学生端 4.13.1 —— 答题卡可折叠、一键收缩、考试窗口能拉得更小

发布：2026-11-04

## 新增

- **答题卡可以折叠**：答题卡右边有个带「←」的小方块，点一下答题卡收起来、题目区占满整个宽度，按钮变成「→」，再点就展开。
- **一键收缩**（只在 Windows 操作题、WPS 文字题出现，放在题目标题栏右边）：点了窗口只留题干，缩成一小条贴在屏幕右上角并且一直在最前面，学生在资源管理器 / WPS 里做题时题目要求一直看得见；按钮变成「还原」，点了窗口回到原来的大小和位置，答题卡折没折也照原样。
  - 网页、AI、拖拽操作题和客观题不出现这个按钮。
  - 收缩着切到另一道 Windows / WPS 题：接着缩着，题干换成新题；切到别的题自动还原。
  - 点交卷、时间到自动交卷、关窗口确认、任何提示框之前，都先自动还原。
  - 收缩时临时放开最小尺寸、窗口置顶；还原时恢复最小尺寸、取消置顶。

## 变更

- 考试窗口最小高度 = 屏幕高的 1/3、最小宽度 = 屏幕宽的 1/8（1920×1080 是 240×360）。窗口窄了、矮了，题目区出滚动条，选项文字跟着窗口宽度换行；顶栏的「交卷」和倒计时排在最前面，窗口再窄也不会被挤掉。离开答题界面后主界面的最小尺寸照旧。
- 题目配图改为紧贴在题干下面（原来会排到作答区下面）。

改动在 `desktop/client/exam_ui.py`（`exam_minsize`、`can_shrink`、`ExamFrame.toggle_card / shrink / unshrink`），`ui.py` 的关窗口确认前先还原。

## 验证

- `desktop/tests/test_ui.py` 新增 10 条：最小尺寸计算、答题时放宽 / 离开换回、窄窗口「交卷」不被挤掉、答题卡折叠展开、按钮只在 win/wps 出现、收缩只留题干与还原放回原样、切题保持 / 自动还原、交卷前还原、时间到自动交卷前还原、关窗口确认前还原。
- 本机（Windows 11，1920×1080）实际起学生端点了一遍，截图在 `D:\Pythonproject\WFXXKJ-ui-shots\`。实测发现 Windows 上收缩时第一次设的窗口位置会被吞掉，已改成设两次并加了断言。
- exe 还没有重新打包、没有在 Win7 学生机上实测；发版时用 `发版.py 4.13.1` 打包后要在机房机器上点一次。
