# 学生端 4.15.0 —— 课堂签到；exe 里的地址槽

发布：2026-11-19（和服务端 2.24.0 同一期）

- 课堂签到：老师发起后客户端弹出签到框锁住窗口，选座号签到，签完或到点自动关；同一台电脑只能给一个同学签。
- exe 的版本信息里留了一段「地址槽」。学校平台「系统管理员 → 下载学生客户端」选「写进 exe」导出的，文件名不变、双击就连本校平台。
- 地址优先级：exe 文件名里的 > 平台写进 exe 的 > 本机记住的 > 打包时内置的。
- 发布页上的 exe 不再内置开发者服务器的地址。
- 「检查更新」升级时，写进旧 exe 的地址原样写进新版。

详细说明见 [2.24.0.md](2.24.0.md)。
