# 教师端 APP 5.2.0 —— 和网页端对齐：在线座次、课堂日志、回收站、数据备份

发布：2026-11-11

逐页对照网页端教师后台，把 APP 缺的功能补齐。

## 新增

- **在线座次**（学生 → 班级 → 在线座次）：读写网页同一张座次表（Jspreadsheet JSON：data / mergeCells / style / 行高列宽 / seatRanges / groups / groupOf / broken）。
  - 自绘座位板 `SeatBoardView`：双指缩放、平移、适应宽度；合并单元格、背景色、字体、边框照网页样式画。
  - 长按拖动换座（边缘自动滚动），规则同网页：有人互换、空座搬过去、故障座位不让放。
  - 点学生：加减分（+1 +2 +5 −1 −2、自定义）、得分记录与撤销、班长 / 组长、分组、离开座位；点空格：标故障 / 修好、改文字。
  - 多选后批量加减分、批量分组、批量标故障。
  - 一键排座（学号 / 随机 / 男女交替、学困生区域、自动识别座位区、跳过故障座位）、小组管理、课堂得分。
  - 学困生标记仅本班老师和管理员可见（服务端控制）。
- **课堂日志**：列表、写、改、删，「从名单里选缺勤的同学」。
- **座次表文件**：班级页显示，可下载、上传替换、删除。
- **回收站**（我的 → 回收站）：按类型筛选、还原、彻底删除、多选、管理员清空。
- **数据备份与系统更新**（我的，仅 root 管理员）：导出、导入（再输密码）、从 GitHub 更新、上传压缩包更新，轮询任务进度和日志（重启期间问不通自动重试）。局域网版服务器没有这块，显示说明。
- **组卷历史**：批量导出（Excel / 学生答题网页 / 两样，zip），批量删除改用 `/papers/bulk-delete`。
- **打字主题**：主题筛选、卡片主题标签、添加 / 导入选主题、批量改主题、主题管理页（新增、改名、启停、排序、删除）。2.15.0 以前的服务端没有主题，入口自动隐藏。
- **数据接口转交**（管理员）。

## 没做的（留在网页端）

- 座次表「导入 Excel 样式」：APP 不带第三方库，读不了 xlsx 样式；在网页导一次，APP 照样显示。
- 全站主题配色、字号：APP 有自己的深浅色设置。
- 学生端地址配置：APP 直接连服务器地址。

## 验证

云端用 javac 对全部模块做了编译检查；用户电脑上 `gradlew assembleRelease` 正式签名打包，androguard 扫字节码没有未定义寄存器。没有在真机上点过。
