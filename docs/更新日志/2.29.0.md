## 每题平均分（`services/paper.even_scores`，迁移 0033）

- 按题型组的卷子：100 分按题数平均，每题一样。40 题 2.5 分、50 题 2 分；除不尽的（43 题）每题按精确值 100/43
  判分，卷面和学生端显示两位小数（2.33），整卷满分仍是 100。2.28.0 里「前面 3 分、后面 2 分」的分法取消。
- 按题型的卷子 `paper_items.score` 不再存分值（存 0），取题时 `load_items` 当场平均分（`force`：卷子配置里
  `by_sections` 明确是 False 才强制）。所以 2.28.0 已经存进去的 2/3 分、已经生成的抽卷，都按平均分算；六大题和
  手工设分的卷子不动。
- 迁移 0033：`exam_submissions` 的 score / objective_score / objective_total / subjective_score / subjective_total
  改成浮点。模型用 `Points` 类型：读出来整数还是整数（3 不是 3.0），小数保留两位。接口里分数字段是 `int | float`。
- 判分：分值是整数的照旧（填空部分得分四舍五入到整数）；带小数的按精确值，总分保留两位小数。
- 老师给操作题评分可以给半分（`apply_manual`）。

## 剩余答题时间（`frontend/src/submitGate.js`）

- `useSubmitGate` 多返回 `remaining`（秒）和 `remainText`。开考时间和交卷门槛共用同一份记录（localStorage），刷新不重算。
- 链接答题页、学生平台答题页左下角固定显示「剩余时间 mm:ss」，最后 5 分钟变红；到点显示「考试时间已到，请尽快交卷」，
  不强制收卷。窄屏时挪到底部交卷栏上面。

## 抽卷考试的成绩分析（`services/analysis.py`）

问题：2.28.0 起开了乱序的按题型卷子每次取卷重抽，分析用的题目是「原卷 + 所有交过卷的抽卷」的并集（八年级那场 154 道），
满分按并集加起来（399 分），于是平均分 66.7/399、得分率 16.7%、总分 98 的学生得分率 24.6%、分数段排到 359–399，
知识范围「155 题、满分 293」，大题得分率判断题 109.4%（满分按每道不同的题算一次、得分按每道题的平均分累加，两边口径不一致）。

现在的口径：

| 指标 | 算法 |
|---|---|
| 每人满分 | 这份答卷自己那一套：`objective_total + subjective_total`（一般 100）；老卷子（没设分）按 100 |
| 平均分得分率 | Σ得分 ÷ Σ每人满分 |
| 及格率 / 优秀率 / 低分率 / 满分人数 | 每人 得分 ÷ 自己的满分 |
| 分数段 | 按每人得分率切十段，标签写成卷面分数（0–10 … 90–100） |
| 名次表、学生对比里的得分率 | 得分 ÷ 自己的满分 |
| 每题得分率 | 只算抽到这题的学生：Σ得分 ÷（人数 × 本题分值） |
| 区分度 | 按得分率排，前 27% 和后 27% 两组里抽到这题的学生的得分率之差；两组里各不到 2 人抽到就不算 |
| 大题 / 知识范围 / 题型得分率 | 各人这部分得分之和 ÷ 各人这部分满分之和（≤ 100%）；「满分 / 平均」是平均每人的 |
| 题数 | 平均每人这部分几题，`pool` 是全场一共抽到过几道（页面上「40（共抽到 154 道）」） |

自动结论里「得分率最低的题」「得分率不到 40% 的题」「区分度偏低的题」只用至少 3 人作答的题。没重抽的考试人人一套，
算出来和原来一样。

用 24 名学生、每人各抽一套的模拟数据核对（`tests/test_exam_rules.py::test_抽卷考试的成绩分析按每人自己那套算`）：
满分 100，平均 50.9（得分率 50.9%），中位数 57.5，最高 95、最低 2.5；分数段十段人数加起来 24；
大题：选择题每人 30 题、满分 75、平均 38.8、得分率 51.7%（全场抽到过 141 道），判断题每人 10 题、满分 25、
平均 12.2、得分率 48.8%；两部分平均加起来 51.0 ≈ 平均分 50.9（各自四舍五入）；名次表里每人得分率 = 分数。

## 学生端考试包（`routers/desk.py`、`services/packcache.py`）

- 考试包的每道题多了 `multi`（多选题）、`blanks`（填空有几个空）。以前漏了，学生端 4.17.0 认得这两项却拿不到，
  多选题全画成单选。考试包里仍然没有答案。
- 包缓存的指纹加上考试时长和包格式版本，老缓存会重建。
- 学生端 exe 用的是原卷（不重抽），每个学生按「考试 + 学号」打乱题序和选项；网页链接答题才每次重抽。
