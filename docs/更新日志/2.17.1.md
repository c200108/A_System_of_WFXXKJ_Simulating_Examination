# 服务端 2.17.1 —— 成绩分析：操作题分题排名

发布：2026-11-04

## 新增

「成绩分析」→「操作题每一步的通过率」：

- 左边的文字只放得下 150 像素，被截断时**鼠标停在文字或柱子上**就弹出完整的框：第几题、题干、这一步的得分点、几人中几人通过。
- 图下面新增「每道题里各步的排名」：**每道操作题单独排**，不同题之间不比。列出名次、小题（①②③…）、得分点、通过率、通过 / 作答人数。可切换「从差到好」（默认，先看最该讲的那一步）/「从好到差」。名次按通过率从高到低定，通过率一样的并列（1、2、2、4）。

小题一列：得分点描述以 ①②③ 开头的（补充题这样写）就用它 —— 一道小题可能拆成几个得分点，几行共用一个 ③；没写的按得分点的先后编号。

接口 `GET /api/exams/{id}/analysis` 的 `operations[].checks[]` 多了 `passed`（通过人数）、`total`（作答人数）。

改动在 `frontend/src/views/ExamAnalysis.vue`、`frontend/src/components/EChart.vue`（类目轴文字 `triggerEvent` 时停在文字上也弹提示框）、`backend/app/services/analysis.py`。
