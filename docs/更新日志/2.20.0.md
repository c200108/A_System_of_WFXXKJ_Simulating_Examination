# 服务端 2.20.0 —— 班级「在线座次」：导入座次样式、一键导入本班学生、随机分座

发布：2026-11-05

## 新增

### 在线座次（班级管理 →「查看」）

- 点开是一个**可浮动的大面板**：右上角「全屏 / 还原大小」「收起」「关闭」。收起后右下角留一个「▲ 某班 在线座次」小按钮，点了展开，表格里没保存的改动不会丢；关闭时有没保存的改动会先问要不要保存。
- 主要区域是本班座次表：双击改字；框选后加粗、左中右对齐、填底色、改字色、加边框、清样式、合并 / 取消合并；右键插入删除行列、调整列宽行高。
- 原来查看里的学生名单去掉了。名单在「学生管理」，班长 / 组长改到「学生管理 → 编辑」里设；面板顶上仍显示人数、男女、班长组长。
- 每个班一张，存在服务器（`classes.seat_sheet`，JSON，最大 2 MB）；**导出 Excel**（带合并、底色、字体、边框、列宽行高）、**打印**（只印有内容的范围，标题「某班 上机座次表」）。
- **导入 Excel 座次样式**：.xlsx 的第一张表，值、合并单元格、填充色、字体（粗体 / 颜色 / 字号）、对齐、边框、列宽行高都带上。原来上传过 Excel 座次表的班可以一键「导入已上传的…」；原来上传的图片、表格文件照旧能看、能下载、能更换。
- 本班老师和管理员能编辑；别的老师打开只能看，拿不到名单。

### 一键导入本班学生（`POST /api/classes/{id}/seat-plan`，`services/seating.py`）

- 区域任意多段、可不连续：`B2:B15, A4:H4, A1:D5`，单格 `C3` 也行；英文 / 中文逗号、分号、顿号、空格都能分隔，大小写都认；也可以在表格上框选后点「+ 加入表格上选中的区域」，框几次加几段。
- 座位顺序：按区域先后、区域里先行后列，重复的格子只算一次；合并单元格只算左上角那一格。
- 选项：随机分座 / 按学号顺序；格子里写姓名 / 学号 + 姓名。
- **男女交错**：按表格坐标给座位分「棋盘色」（行号 + 列号奇偶），人多的性别占座位多的颜色，左右、上下相邻的就是一男一女；人数不均时多出来的人补进剩下的座位，没填性别的谁的位置都能坐。
- **学困生分配固定区域**：另写一块区域（也能框选加入），学困生优先排进去，可以和男女交错一起开；区域放不下的排到区域外并提示，区域里剩下的座位给其他同学。
- 座位比学生多：多出来的留空并提示；学生比座位多：列出没排到的人。要覆盖已经写了字的格子先确认。服务端只算不存，填进表格后老师看过再点「保存」。

### 学困生标记（`students.struggling`）

- 学生管理：编辑框里开关、列表一列「学困生」、勾选后批量「设为学困生 / 取消学困生」，顺带能批量「设为男生 / 设为女生」。
- 导入：Excel 模板和粘贴名单第五列「学困生」，填「是」（√、1 也认）就是。
- **隐私**：只在老师 / 管理员的学生接口（`StudentAdminOut`）里出现，而且老师只看得到自己班的；学生登录、`/api/student/me`、学生首页等一律不带。座次表里不标记学困生，导出、打印也不会带出去。

## 选型（为什么是这两个库）

| | 选了 | 没选 |
|---|---|---|
| 表格本体 | **Jspreadsheet CE 5.0.4**：MIT 许可，2025 年仍在更新，约 300 KB，支持合并单元格、单元格样式、列宽行高、只读模式，纯 JS 好嵌进 Vue | Univer（Apache-2.0，功能全但体积大好几倍）；Handsontable（非商用许可）；x-spreadsheet、Luckysheet（已停更） |
| 读写 Excel | **ExcelJS 4.4.0**：MIT 许可，能读写合并单元格、填充色、字体、边框、列宽行高 | npm 上的 xlsx@0.18.x（有原型污染 CVE，且社区版不读样式） |

- 两个库都**懒加载**：只有点开「在线座次」才下载（Vite 拆成单独的 `sheet-*.js` 约 490 KB、`excel-*.js` 约 940 KB），平时的页面不背；局域网版全部打包进 `web/`，**不走 CDN**。
- Jspreadsheet 自带的工具栏图标要从 Google 加载 Material Icons 字体（局域网会显示成一串英文），所以没用它，自己做了加粗 / 对齐 / 颜色 / 边框 / 合并几个按钮。
- 安全：`npm install` 改走 https 官方源；`npm audit --omit=dev` **零高危**（顺手修掉了原有的 follow-redirects、source-map-js 两个高危；ExcelJS 依赖的 uuid 用 overrides 升到 11.1.1）。剩一个原有的 echarts 中危（XSS，要升 6.x 大版本），这次没动。
