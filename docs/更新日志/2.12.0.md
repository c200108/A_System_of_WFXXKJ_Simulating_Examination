# 2.12.0 —— 打字学情分析；打字成绩筛选、排序、批量删除

发布：2026-09-30

## 一、学情分析页

「打字成绩」页右上角「学情分析」，新标签页打开（`/js/typing-analysis`），和考试的「成绩分析」一个样子。

**看什么、看谁**

- 模块：中文 / 英文 / 键盘 / 全部；时间：近 7 天、30 天、90 天、全部；
- 全体 / 按班级 / 学生对比（最多 8 人）；选择记在地址栏里，链接发给别的老师打开是同一个视角；
- 每 30 秒自动刷新，切到别的标签页时暂停；可打印。

**有哪些图和数**

| 部分 | 内容 |
|---|---|
| 指标 | 练习人次、参与人数（人均次数）、平均速度、中位数 / 最快、平均正确率、达标率（两星及以上）、三星、平均用时、累计分钟、只练过一次的人数 |
| 走势 | 每天（跨度超过两个月按周）练习人次、平均速度、平均正确率；没人练的日子也列出来 |
| 分布 | 速度段（格子宽度按最快的自动定）、正确率段、星级、难度（占比、速度、正确率、达标率）；选「全部」时加各模块一览 |
| 班级 | 平均速度、正确率与达标率、各班速度箱线图；参与率 = 练过的人 / 学生名单人数 |
| 学生名单 | 名次、练习次数、最快、平均速度、正确率、达标率、**进步**、最近一次 |
| 学生对比 | 每人每次练习的速度、正确率折线 |

每张图都能展开看原始数字。

**口径**（`services/typing_analysis.py`）

- 一个学生 = 班级 + 姓名（账号练的和免登录页练的合在一起算）；
- 速度只在单个文字模块里比：中文字/分和英文字母/分不能混，键盘没有速度。选「全部」或「键盘」不出速度的图；
- 各班先在学生身上平均、再在学生之间平均，练得多的不会把全班的数拽走；
- 进步 = 最后 3 次减最初 3 次（键盘用正确率），练满 4 次才算。

**自动结论**举例：整体水平和达标率；正确率低于 80% 的练习反而更快时，提醒「先准后快」；
前后半段走势；班级之间最好最弱；参与率最低的班还有几个人没练过；只练过一次的人数；
简单难度占七成以上且达标率高时，建议挑战中等；进步最明显的三人；退步的人数；学生对比时每人一句。

## 二、打字成绩页

- 筛选：班级、模块、难度、姓名、日期范围；
- 排序：点表头，服务端排（`GET /api/typing/records/search`），翻页不乱；
- 分页：20 / 50 / 100 / 200 条一页；
- 批量删除：勾选删除（`POST /api/typing/records/delete`），或「删除筛选出的全部（N）」
  （`DELETE /api/typing/records` 现在认和筛选一样的条件）—— 删掉的正是看到的那 N 条；都要删除权限；
- 导出 Excel 按当前筛选导出。

原来页面右边的正确率分布、各模块、各班平均几张小图挪进了学情分析页。
