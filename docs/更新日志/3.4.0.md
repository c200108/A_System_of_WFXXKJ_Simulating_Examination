# 3.4.0 —— 考场里的文件，得和题干说的一模一样

发布：2026-09-21　｜　同期：学生桌面端 4.7.0

老师拿新补的题一道道对了一遍，指出两处：**Win 题的文件夹结构和题干对不上**，
**WPS 题生成的文章和题目毫无关系**。都是真问题，这一版全部改掉，并且把每一条
都钉进了测试。

---

## 一、Win 题：题干说什么，考场里就得有什么

以老师指出的那道为例：

```
Win操作题
请打开本题工作目录（C：\EXAM\Win操作）按照要求进行作答。
（1）打开网页文件“安全教育网.htm”，在网页中找到“火灾逃生方法”视频资料，
     以“火灾逃生.rar”为名保存到“ks\消防安全”下。
（2）在“ks”文件夹中，新建一个名为“校园安全”的文件夹。
（3）将“ks”文件夹中的“安全乘车.docx”文件移动到“交通安全”文件夹中。
（4）将“ks”文件夹中“实验安全”文件夹中不合适的文件删除。
```

### 改之前

```
C:\EXAM\
    ks\                    ← 空的
    交通安全\               ← 位置不对，题干说它在 ks 里
    安全乘车.docx           ← 位置不对
```

**连「Win操作」文件夹都没有** —— 工作目录写在括号里，解析器只认
「本题工作目录下的 X 文件夹」那一种写法。(1) 和 (4) 两问完全没解析出来，
素材自然也没铺。学生打开工作目录，里面空空如也。

### 改之后

```
C:\EXAM\Win操作\
    安全教育网.htm          ← (1) 要打开的网页，里面真有那条资料的链接
    资料\火灾逃生方法.rar   ← 网页里链的那份资料，真能下下来
    ks\
        消防安全\           ← (1) 的保存目标
        交通安全\           ← (3) 的移动目标
        安全乘车.docx       ← (3) 要移动的文件
        实验安全\
            无关文件.txt    ← (4) 要删的那一个
```

四问全部有检查点。**答案一个都不预先铺**：「火灾逃生.rar」「校园安全」是学生
要做出来的，环境里没有。

### 具体改了这些

| 题干里的说法 | 原来 | 现在 |
|---|---|---|
| 工作目录（C：\EXAM\Win操作） | 认不出，全落在考试根下 | 认出来，工作目录是 `Win操作` |
| 「ks」文件夹中的 X 移到「交通安全」 | X 铺在根上，交通安全也在根上 | 都在 ks 里（题干那句 `ks\消防安全` 就是证据） |
| 打开网页文件…找到 X 资料 | 铺个占位文本，做不了 | 铺一张真网页 + 一份真资料 |
| 删除「医学」文件夹中不属于…的文件 | **把「医学」整个删了** | 在里面铺一个不相干的文件，删它 |
| 移动到**对应的**文件夹中 | 建了个真叫「对应的」的文件夹 | 这一问机器判不了，不出检查点、不建文件夹 |
| 将**文件**「房屋」重命名为… | 铺成了文件夹 | 按题干说的，铺成文件 |
| 新建一个 word 文档，文件名为「打印材料」 | 没认出 | 补上 `.docx`，判它在不在 |

还有一条兜底：**题干点过名、又没被任何规则铺出来的文件和文件夹，一律补铺**。
认不出某一问不要紧（那一问不判分），但不能让学生打开文件夹发现题目说的文件
根本不存在 —— 他会以为自己找错了地方，在那一问上耗掉整场考试。

## 二、WPS 题：文章要和题目有关，题干引的原话要真在文档里

同样是老师指出的那道：

```
李雯正在编辑“孔子对中华文明的贡献”文稿……
①将文章的标题设置为“标题”样式，并为正文第一自然段中的文字
  “孔子整理的《诗经》和孔子的诗论，是两千多年来中国文学的源头活水。”添加“双下划线”；
```

### 改之前

```
标题段：样式，并为正文第一自然段中的文字        ← 正则从两个引号中间捞出来的废话
正文：  文档正在深刻改变我们的学习与生活……      ← 和孔子毫无关系
```

题干要加双下划线的那句话**根本不在文档里**，检查点却指着它 —— 判出来的"通过"
是假的，学生怎么做都对不上。

### 改之后

```
标题段：孔子对中华文明的贡献
正文段1：孔子整理的《诗经》和孔子的诗论，是两千多年来中国文学的源头活水。
         这一点，正是读孔子对中华文明的贡献时最值得留意的地方。
正文段2：《孔子对中华文明的贡献》是这次要整理的文稿。通读一遍会发现……
正文段3：文章围绕孔子对中华文明的贡献展开：先摆出事实，再讲道理……
```

两条硬要求，现在由代码保证：

1. **题干抄出来的每一句原文都原样出现，而且各自独占一段。** 检查点是按内容找
   段落的：两句挤在一段里，两套格式会互相覆盖；少了哪一句，学生翻遍文档也找
   不到要改的地方。
2. **别的段落也围着这个题目写。** 不再是"XX正在深刻改变我们的学习与生活"那种
   谁都套得上的模板。

顺带修掉三个会造出**假检查点**的 bug：

- 「设置为"标题"样式」里的样式名被当成标题内容（就是上面那段废话的来源）。
- 字体名用了通配写法（`华文` + 任意两三个汉字），于是
  「孔子对中华文明的五大贡献.pdf」里的"华文明的五"被当成字体 ——
  **一条学生永远做不到的检查点**（字体下拉里没有这个字体）。
- 「插入艺术字"家国情怀"」里的"家国情怀"被当成正文原话塞进了文档。

题干里抄原文常带省略号（`"李绅（772﹣846）……被誉为'悯农诗人'。"`），
现在会把两截接成一句通顺的话再放进文档，而不是只留前半截。
