# 学生端 4.9.0 —— 刷新 3 秒一次；打字守平台的防刷规则

发布：2026-09-24（同期平台 2.11.0，详见 [2.11.0.md](2.11.0.md)）

- 右上角「刷新」点过之后灰 3 秒。
- 打字练习：
  - 打完一半才能交（服务端配置 `min_done_ratio`，exe 不限时，只认字数），没到就在按钮旁说还差多少字；
  - 一分钟内再交会被服务端挡回来：这次的成绩扣着、停表、锁住输入框，倒数完自动再交，不用重敲；
  - 「换一段」每分钟最多 3 次，被挡时按钮上倒数，手上那段不丢；
  - 取过的文本记在程序里，刷新、切页、切回原模式不再去要，不占次数。
- 每个请求带 `X-Device-Id`（机器名 + 网卡地址算出来的，不存文件），服务端靠它认「同一台电脑」。

**4.8 及以前的 exe 交不上中文、英文打字成绩**（不带文本长度），学生机请换成这一版；考试交卷不受影响。
