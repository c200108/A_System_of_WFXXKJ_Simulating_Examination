# 教师端 APP 5.2.1 —— 修「在线座次」空白

发布：2026-11-11

## 修复

- 在线座次打开一片空白：工具栏里的占位 View 用了 `V.fill()`（高度 WRAP_CONTENT），普通 View 在 AT_MOST 下会取满可用高度，把工具栏撑成整页，带权重的座位表区域只剩 0 高。改回 `V.spring()` 自带的 1px 高。小组管理里同样的写法一并改掉。
- 座位表数据比界面晚回来时，`onSizeChanged` 不会再触发，原来就不会自动「适应」宽度；现在 `setSheet` 第一次拿到表且已量好尺寸时直接适应。
- CSS 8 位颜色 `#RRGGBBAA` 按安卓的 AARRGGBB 读反了，改正。

## 变更

- 服务器上还没有座次的班，和网页一样显示学校默认空表（`frontend/public/seat-default.xlsx` 用网页同一套 `sheetFromWorkbook` 转成 JSON，放在 `feature-student/src/main/assets/seat-default.json`），保存后才写服务器。换了默认空表要重新转一次。

## 验证

云端 javac 编译检查；用户电脑正式签名打包，androguard 扫字节码。真机看过 5.2.0 的空白截图，5.2.1 待真机确认。
