# 服务端 2.20.1 —— 在线座次：默认空表、逐格导入、全屏浮窗、点卡片打开

发布：2026-11-06

## 新增

- **默认空表**：没画过座次表的班，打开在线座次就是学校的「信息课座次表」空表（`frontend/public/seat-default.xlsx`，打包进前端，局域网版不联网也有）。「清空」也回到这张表。读不到这个文件时退回原来的「讲台 + 空格子」。

## 变更

- **导入 Excel 座次样式逐格照搬**（读取规则单独放在 `frontend/src/components/seatExcel.js`，不依赖 Vue，能在 node 里拿真实 xlsx 测）：
  - 值：字符串、数字、富文本、公式结果、超链接文字、日期；合并区域里被盖住的格子留空。
  - 字体：字体名、字号（磅 × 4/3 = 像素）、加粗、斜体、下划线、删除线、字色。
  - 底色：实心填充前景色；颜色支持 argb、主题色（读文件自带主题，读不到用 Office 默认）+ tint、常见 indexed。
  - 边框：四边分别取，细 / 中 / 粗 / 双线 / 虚线 / 点线、颜色；合并区域的右、下边框从最右列、最下行的格子上取。
  - 对齐：水平（含跨列居中、分散）、垂直（Excel 默认靠下）、缩进；换行照原文（表格每列自动换行，原表的回车照样分行）。
  - 列宽（字符 × 7 + 5 像素，没设的用表的默认列宽）、行高（没设的用默认行高）、隐藏列。
  - 范围按「有字 / 有边框 / 有底色 / 在合并区域里 / 设了行高」收，最多 200 行 × 60 列；WPS 常把列定义写到第 258 列，不再照 dimension 带出空列。表格不再硬凑成至少 12 列 × 14 行，原表几行几列就是几行几列。
  - 合并区域里被盖住的格子不写样式：表格库会把它们的样式叠到左上角，原来讲台 F19:H19 因此从居中变成靠左。
- 导出 Excel 带上字体名、斜体、下划线、删除线、垂直对齐、边框粗细 / 线型 / 颜色；打印时表格自己有边框就照它的来，不再每格补一圈灰线。
- **班级卡片**：去掉「查看 ›」；点卡片任意空白处（班名、人数也算）打开在线座次，点勾选框、下拉、按钮、链接不跳，正在选字也不跳。上传的图片座次表那个按钮改叫「🖼 看图片」，免得和原来的「查看」混。
- 每个年级一块浅底色区域，年级名左侧色条、18px 粗体；两个年级之间一条虚线分界。卡片边框 1.5px、带阴影、悬停高亮，班级名 17px。

## 修复

- 导入座次样式报「读不了这个文件：Cannot read properties of null (reading 'toString')」。原因：ExcelJS 对合并区域里被盖住的格子取 `cell.text` 时去读左上角的值，左上角空着（如用户空表的 F3:I3）就对 null 调 toString。现在自己按值类型转文字，被盖住的格子直接给空。
- 在线座次「全屏」过大：原来全屏贴满四边，表格高度按「窗口高 − 150」估，工具栏折成两三行时表格撑出窗外。现在全屏是居中浮窗（上下各留 4%、宽 92%，最宽 1600px）；表格区用 flex 占满面板剩下的高度，`ResizeObserver` 量出实际高度再设给表格滚动区，拉窗口、全屏 / 还原都自动适配。

## 验证

- node 里用用户空表跑 `sheetFromWorkbook`：22 行 × 9 列、8 个合并（C1:G1、F3:I3、F18:G18、H18:I18、A19:B19、C19:D19、F19:H19、E3:E19）、走廊换行、隔格的绿色字（原表就是 #339966）、黑体 14 磅都对。
- 浏览器（本机 vite + 临时 sqlite 后端）：新班打开即默认空表；导入这张空表不再报错；一键导入 30 人到 B3:B18, D3:D18, G4:G17, I4:I17 后保存、关闭再打开，样式和名字都在；1440×900、1280×680 下全屏和还原，表格底边都在浮窗里；点卡片空白、班名能打开，点下拉、勾选框不打开。
