# 2.13.0 —— 学生可以用中文姓名登录（给学生端姓名登录版）

发布：2026-10-08（同期学生端 4.10.0，详见 [4.10.0.md](4.10.0.md)）

## 要什么

学生端另出一版：账号是学生的中文姓名，初始密码统一 123456。原来的学号登录不能动 —— 机房里还有大量
旧 exe，学生习惯了「初始密码就是学号」。

## 怎么做的

**不新建账号、不改库**。姓名登录认的还是那个学生账号，只是换个认人的办法：

- 新接口 `POST /api/student/login-by-name?name=&password=`；
- 「还没改过密码」= 密码哈希仍对得上学号初始密码（`still_initial`）。这种账号走姓名登录**只认 123456**，
  不认学号 —— 学号同学之间都知道，拿姓名 + 学号就能登别人的号；
- 改过密码的账号两种登录都只认新密码；老师重置密码后回到初始状态，123456 又能用；
- 学号登录 **不认** 123456，旧客户端的规矩一点不变；
- 改密码时原密码填 123456 也算对（姓名版学生只知道这个），但新密码不能是 123456。

**重名**：同名的几位里，谁的密码对得上就是谁；都还用 123456（对得上不止一位）时分不出来，回 409 提示
改填学号 —— 姓名这一栏同时认学号。停用的账号回 403。姓名前后的空格去掉再比。

## 验证

`backend/tests/test_student_name_login.py` 11 条：姓名 + 123456 能登、学号登录不变、错密码 / 查无此人、
改密码后 123456 失效且学号登录也换新密码、不许改成 123456、重置后恢复、重名提示学号、
重名但密码不同各认各的、停用、姓名登录不认学号初始密码、旧客户端用学号当原密码照样能改。

## 升级注意

只加了接口，没有数据库变化。服务器 `git pull && sudo docker compose up -d --build`。
