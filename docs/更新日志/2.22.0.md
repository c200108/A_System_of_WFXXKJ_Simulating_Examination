# 服务端 2.22.0 —— 界面主题、在线座次缩放 / 批量操作 / 自动识别座位 / 设备故障

发布：2026-11-06

## 新增

### 全站界面主题（`frontend/src/theme.js`、`components/ThemePicker.vue`）

- 7 套配色：默认（原来的 Element Plus 蓝）、明快蓝、代码灰蓝、薄荷绿、靛紫、暖橙、高对比（机房投影）。
  配色思路参考 Ant Design、GitHub Primer、Naive UI、Tailwind CSS、Material Design 3，只借配色，没有引用它们的代码或资源。
- 4 档字号：标准 14 / 稍大 15（默认）/ 大 16 / 特大 17，Element Plus 的几档字号一起放大。
- 做法：生成一段覆盖 Element Plus CSS 变量的样式挂到 `<head>`；主色、成功、警告、危险色的 light-3…light-9、dark-2 梯度按 Element Plus 自己的算法（和白 / 黑混色）算出来；底色、文字色只在浅色模式改，深色模式照常。
- 存在服务器 `app_meta`（`ui_theme`、`ui_font`），`GET /api/config` 多一项 `ui`，所有人都一样；`PUT /api/config/ui` 修改。
  在线版只有系统管理员能改（`require_root`），入口在「我的账号 → 数据备份与系统更新」最上面；机房版没有那一块，管理员在「我的账号 → 界面主题」里改。
- 点卡片先在自己这里预览，「应用到全站」才保存；取不到配置时按默认主题、稍大字号。

### 在线座次

- **缩放**：工具栏「－ / 比例 / ＋ / 适应」，50%–200%；「适应」按表格区宽高（扣掉课堂日志栏）算出放下整张表的比例。用 CSS `zoom`，只改显示；滚动区 max-height 按比例除回去，正好占满表格区。每人记在浏览器 localStorage（`seat-zoom`）。
- **框选批量**：在选区里右键（右键按下时不让表格库把选区改成单格），选区里有两位以上学生就出批量菜单：一起加减分（`POST /api/classes/{id}/points/bulk`，学生必须都在本班，一次最多 200 人）、一起分组。
- **自动识别座位**：认「字母 + 数字」的座位号格子（A1、B12、AB3），它右边那格（空的或坐着学生）就是座位；按座位号排序，同列连续的并成一段（B3:B18）。一键导入弹窗里「🪑 自动识别座位」，第一次打开自动认。
- **设备故障**：座次表 JSON 多存 `broken: {格子: 说明}`。右键空座位（座位号旁的空格或已标故障的格子）出「标成设备故障 / 修好了」；工具栏「🔧 设备故障」对选区切换；右键学生也能标他的座位（先清空）。显示红色斜纹 + 🔧 说明（`data-broken`，不写进格子样式）；一键排座时和合并格一起进 `skip`；拖动换座拒绝；打印显示「设备故障：说明」。

## 变更

- 在线座次去掉「收起」按钮：在面板外按下鼠标就收成右下角小按钮。面板、小按钮、右键菜单、拖动名牌、Element Plus 的弹层 / 下拉 / 提示、表格库的右键菜单都不算「外面」。点班级卡片打开别的班时自动展开。
- 全屏时表格和课堂日志的间距 `clamp(24px, 3vw, 64px)`、日志栏宽 `clamp(330px, 24vw, 440px)`；普通大小照旧挨着。
