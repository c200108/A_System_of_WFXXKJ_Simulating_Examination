## 一、拖拽作答区（`client/dragboard.py`）

### 学生看到的

上面一排是素材卡片，下面是题目的图 —— 流程图、网络结构图、设备归类框、带空位的
程序。按住卡片拖到绿色虚线框（热区）里松手，就放进去了：

- 大多数热区只能放一张。再放一张，原来那张自动退回素材区；
- 从热区里拖出来、松在热区外面，就是拿回来；
- 归类题的大框能放好几张；
- 程序填空的空位嵌在代码行里（①②），代码排序题一行一个空位。

答题卡上这题显示「已放 N 张卡片」。每放一次都写草稿，机房跳闸重开，卡片还在原位。

### 图从哪来

服务端按原题**重画**的：框、线、热区、卡片，一份 JSON。原题配图是旧考试系统的截图，
素材区和说明弹窗都烤在图上，没法当底图，所以拖拽题不再发那张截图。网页端用同一份
数据画 SVG，两边长一个样。

### 怎么画、怎么拖

- **状态就是一份映射** `{"placed": {"A": ["i1"]}}`。每次松手改映射，然后**整块重画**，
  不去一个个挪画布上的图形。几十个图形重画一次不到一毫秒，换来的是界面永远和状态
  一致：草稿恢复、交卷、判分看到的是同一份东西。
- 落在哪个热区按松手时的指针位置算；热区套热区（大框里还有小格）时取**最小**的那个。
- 代码卡片左对齐、用新宋体（NSimSun：等宽、带中文，中文 Windows 都有）。居中显示
  的话缩进全看不出来，代码排序题没法做。
- 显示的每个字都能编进 GBK（Win7 字形规则，`test_win7_glyphs.py` 守着）。题目里
  本来的 a² 写成了 a×a。

### 交卷

`states.collect()` 加了 drag 分支，交的就是这份映射，**一张没放也交 `{"placed": {}}`**。

这一点有讲究：服务端靠它区分「新 exe、学生没做」（照常判 0 分）和「旧 exe 根本做
不了」（旧版交的是空的 `{}`，留给老师评阅）。详见 3.5.0.md 的升级注意。

## 二、本机 IP 查询

这道题考的是"会用命令查本机地址"，所以查的是**真机**：

- 「打开命令提示符」按钮开一个真的 cmd 窗口，学生敲 `ipconfig`；
- 查到的地址填进输入框，格式不对当场提示（四组 0～255 的数字，用点隔开）；
- 交卷时客户端顺手收一份本机真实的 IPv4 列表，服务端看填的在不在里面。

本机地址两条路一起查、合起来去掉 127.x：按主机名查在多网卡、装了虚拟网卡的机器上
只给一部分；`ipconfig` 最全，但万一被组策略禁了也不能让交卷卡住。`ipconfig` 的
输出是 GBK，按 GBK 解。

**网页端仿真命令行里那个地址不进考试包**；exe 交上来的，服务端也**只认真地址**。
仿真地址是固定的，练过网页版的学生都见过。

## 三、打字练习：首页三个数一直是 0

**症状**：在 exe 里练了好多次打字，首页的「练习次数、最快速度、平均正确率」还是 0；
网页端练的就算得上。

**原因**：exe 交打字成绩时**没带登录令牌**。服务端照样收下成绩，老师在后台看得见，
但不知道是谁的，没挂到学生账号上，而首页只统计挂了账号的记录。交卷那条路 4.4.0
修过同一个问题（按学号认领），打字这条漏了。

**修法**：

- exe 交成绩带上令牌（`api.typing_submit(..., token=)`），同时带上学号；
- 服务端令牌优先；没令牌或令牌过期了，按学号认领（学号全校唯一）。认不上的照旧
  入库，不挡着交成绩。

只换 exe、服务端不升级也能好，因为旧服务端也认令牌（多出来的 `student_no` 字段它会
忽略）。令牌过期时按学号认领，这一步要新服务端。

## 四、WPS「标题 1」被判成「样式是 2」

WPS 存 .docx 时样式编号是数字（`w:styleId="2"` 就是它的「标题 1」），客户端原来
直接拿编号当样式名。现在先读 `word/styles.xml`，按编号查**名字**：heading 1 和
标题 1 这类写法统一成「标题1」，查不到名字的看大纲级别。

**不能按编号猜**：同一个 "2" 在中文 Word 里是「标题 2」。测试里两种文档都钉着。
