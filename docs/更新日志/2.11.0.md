# 2.11.0 / 4.9.0 —— 打字防刷；exe 刷新 3 秒一次

发布：2026-09-24

## 一、打字练习的三条规则（服务端把关，网页和 exe 都守）

| 规则 | 默认 | config.yaml（`typing:` 下） |
|---|---|---|
| 中文、英文要打完一半才能交 | 0.5 | `min_done_ratio` |
| 同一台电脑两次交成绩至少隔 | 60 秒 | `submit_interval_sec` |
| 同一台电脑每分钟最多换文本 | 3 次 | `passage_per_minute` |

三项填 0 都是不限。改完重启后端即可，不用重新构建前端。

**「打完一半」的口径**：敲的字数 ≥ 文本长度 × min_done_ratio；**限时练习练满一半时间也算**。
一篇练习文本是 7～9 段拼起来的，英文简单难度一篇四五百个字母，1 分钟限时的练习谁也敲不完一半
—— 只认字数的话，限时练习就永远交不上了。exe 不限时，只认字数。键盘模块不管这一条。
网页上没打完就点「结束并交成绩」会先弹框说还差多少，确认结束则这次不记成绩；到点自动结束的照常交。

**「一分钟只能交一次」被挡回来的那次不丢**：成绩先扣着、停表，倒数完自动再交（网页、exe 都是）。

**「换文本」怎么算**：每次向服务器要一篇新文本算一次 —— 网页端每点一次「开始」，exe 点「换一段」
或者切到一个没取过的模式 / 难度。exe 取过的文本记在程序里，刷新、切页、切回原模式都不再去要。

### 「同一台电脑」怎么认

请求头 `X-Device-Id`：网页端第一次用时生成一个随机号存在浏览器里，exe 按机器名 + 网卡地址算
（不存文件，机房还原卡一重启文件就没了）。都没带（旧版学生端）才退回认 IP。

**不能只认 IP**：线上服务器那边，整个机房的学生机走同一个出口 IP，认 IP 就成了全机房每分钟只能交一次。
设备号是客户端给的，清掉浏览器数据就换了一个 —— 校内工具，防的是手快乱点，不是防攻击。

### 计数落库

新表 `rate_hits`（迁移 0016），只留最近一小时。后端开了好几个工作进程（`WEB_WORKERS`），
计数放内存里各算各的等于没限。**不跟着数据导出导入**（和 app_meta 一样在 SKIP_TABLES 里）。

### 旧版 exe

交成绩要带「这段文本多长」（`target_chars`），4.8 及以前的 exe 不带，**中文、英文成绩交不上来**，
提示「学生端版本太旧」。学生机换成 4.9.0 即可；键盘模块、考试交卷不受影响。

## 二、exe 右上角「刷新」3 秒一次

每点一下就把这一页的接口全打一遍，一个机房几十个人一起狂点，服务器就是被这么点慢的。
点过之后按钮灰 3 秒。

## 测试

- 后端 `tests/test_typing_limits.py`（11 条）：一半规则、限时练满一半时间、旧版客户端、
  每分钟一次、没交上的不占名额、按设备号 / IP 认、每分钟三次文本、没取到文本不算、填 0 不限、不跟着导出导入。
- 桌面端 `test_ui.py`：刷新 3 秒、没打完一半交不了、被挡的那次停表并自动再交、取过的文本不重取、
  换一段第 4 次被挡且手上那段不丢；`test_typing_link.py`：带上文本长度、设备号稳定且格式对。
- 其余测试默认把三条规则关掉（`conftest.py` 的 `_typing_limits_off`），它们一分钟里要交好几次。
