# 教师端 APP 5.1.2 —— 检查更新找得到测试版、API 标签、学生学情

发布：2026-11-03

## 检查更新找不到 5.1.1（老师报的问题）

5.1.0 里点「检查更新」提示「还没有发布过教师端 APP 的安装包」。原因：teacher-v5.1.0、teacher-v5.1.1 在 GitHub 上都是
**预发布**，而 5.1.0 只认正式版 —— 一个都挑不出来，就当成「没发布过」。

现在（`feature-me/AppUpdate.java`）：

- 正式版、测试版分开找。有更新的正式版就提示正式版；没有、但有更新的测试版，就提示「发现测试版 vX（预发布）」并写明
  「还没转成正式版，可能还有问题」，老师自己决定装不装；
- Release 列表一次取 100 条（原来 30 条，学生端每次发版也占一条，迟早翻不到 APP）；
- GitHub 限制查询次数（同一出口 IP 每小时 60 次，整栋楼一个出口时会碰到）时提示「请过一会儿再试」，不再笼统说连不上。

**已经装着 5.1.0 的手机**：它还是旧逻辑，只认正式版。要么把 5.1.2 发成正式版（不勾 Latest），要么手动装一次 5.1.2，之后就能在 APP 里升级了。

## 新增

- 底部新增「API」标签（和网页版「API」一致）：列表、新建；每个 API 里「数据」「来源网页」「图表」「接入」四页，
  可暂停接收、导出 Excel、删除。字段命名、来源白名单等复杂设置在网页上改。要配 2.16.0 服务端。
- 学生详情里新增「学情」：考试成绩与名次、打字、教学网页数据。
- 底部六个标签，选中底块从 56dp 收到 52dp，360dp 宽的手机也放得下。

## 验证

云端没有 Android SDK：用安卓 15 系统库把全部模块编译了一遍（通过）；`AppUpdate.pick` 拿 GitHub 上真实的 Release 列表跑，
挑出测试版 5.1.1（apk 名、大小、sha256 都对）。界面没有在真机上看过，需要在手机上验。
