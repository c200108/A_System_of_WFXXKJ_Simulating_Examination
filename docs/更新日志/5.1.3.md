# 教师端 APP 5.1.3 —— 「接入」里复制 AI 提示词

发布：2026-11-03

## 新增

「API → 某个 API → 接入」最上面加了两行：

- **复制 AI 提示词**：取服务端生成的提示词（和网页版同一份，见服务端 2.16.1）放进剪贴板；
- **分享 AI 提示词**：用系统分享发到电脑（微信、QQ 文件传输助手），在电脑上再交给 AI。

提示词每次点都现取（`DataApiClient.aiPrompt`），接收地址按 APP 连的服务器地址拼（传 `base=Http.absolute("/")`），
和「接入」页显示的接收地址一致。新建 API 后的提示也改成「在『接入』里复制 AI 提示词交给 AI 做网页」。

要配 2.16.1 以上的服务端；旧服务端没有这个接口，点了会提示接口不存在。

## 变更

「考试详情 → 考试设置」和「发布考试 / 修改设置」里「允许提前交卷」开关的说明改为：默认要考试时间过一半、并且答完一半的题才能交卷（服务端 2.17.0 起交卷门槛从三分之二改成一半）。

## 验证

本机 `gradlew :app:assembleDebug` 编译通过。界面没有在真机上看过，需要在手机上验。
