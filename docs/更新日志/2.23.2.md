# 服务端 2.23.2 / 学生端 4.15.0 —— 黄条改成置顶提醒；打字限时按难度带默认值；导出的学生端带本网站地址

发布：2026-11-19

2.23.0 的组卷页黄条会自动显示需求反馈区最近 24 小时的最新消息。现在改成：只显示管理员置顶的反馈，教师端每个页面都显示。

## 后端（`routers/community.py`）

- `feedbacks` 加 `pinned_at`、`pinned_until`（迁移 `0026_feedback_pin`）。`pinned_until` 为空表示不限期。
- `PUT /api/feedback/{id}/pin {days}`（管理员）：`days=0` 不限期，1～30 天。只能置顶审核通过的反馈；最多同时置顶 5 条，超了回 409。已置顶的再调一次就是改期限。
- `DELETE /api/feedback/{id}/pin`（管理员）：取消置顶。
- `GET /api/feedback/news`（登录的老师）改成返回 `{items: [...]}`：置顶中、没到期、仍公开的反馈，按置顶时间倒序。每条带作者、类型、内容摘要、回复数、最后一条回复，以及 `id = p<反馈号>-<置顶时间>`。被撤下（拒绝）的自动不显示。
- 公开列表 `GET /api/feedback`：置顶的排最前，每条带 `pinned`、`pinned_until`。

## 前端

- `components/FeedbackNews.vue` 从 `Paper.vue` 挪进 `layouts/TeacherLayout.vue`，登录后教师端每个页面顶上都有。置顶几条就显示几行。点 × 按条记在 localStorage；取消后再置顶，`id` 会变，所以会重新提醒。切页面时最多每分钟刷新一次；管理员在反馈页置顶或取消后立刻刷新。
- `views/Feedback.vue`：管理员在每条反馈旁边能「置顶」（弹框里选不限期或 1～30 天）和「取消置顶」，置顶中的反馈带「置顶到 xx / 置顶 · 不限期」标签。

## 打字限时

- `typing.time_limits` 默认加上 20、30 分钟：`[1, 2, 3, 5, 10, 20, 30]`。
- 新增 `typing.default_limits`，默认 `{简单: 5, 中等: 10, 困难: 20}`，放在 `/api/typing/config` 里返回。网页（/dazi 和学生平台）选难度时自动带出对应限时，学生还能再改。
- 学校自己的 config.yaml 如果还是老的档位（没有 20），对不上档位的那一项会被去掉，退回 `default_limit`，服务照常启动。**升级后想要 20、30 分钟档，要在服务器的 config.yaml 里给 `time_limits` 加上 20、30。**

## 导出学生端 exe 带本网站地址

原来「下载学生客户端」是浏览器直接下 GitHub 附件，那些 exe 打包时烤的是开发者自己服务器的地址：别的学校部署了，学生端也连到那儿去，地址还公开了。

- 学生端 4.15.0：打包时给 exe 加版本信息（`build.py` 的 `write_version_file`），「备注」里留一段 `WFXXKJ-SERVER=` + 120 个 `~` 的占位，UTF-16 原样存在 exe 里。导出时把占位换成地址，长度不变，exe 别的字节不动。程序启动时读自己的 exe（`client/slot.py`、`shell.slot_server`）。地址优先级：文件名 > 写进 exe 的 > 本机记录 > 打包内置。自检报告多一栏「网站写入」。
- 「检查更新」升级：旧 exe 里写着地址的，原样写进新版的地址槽（`update.carry_slot`）；新版没有槽就退回把地址补进文件名。
- 服务端：`GET /api/system/clients` 列出能导出的 exe；`GET /api/system/clients/{名字}?how=name|slot&addr=…` 导出。`how=name` 改文件名（`原名@主机_端口.exe`，内容不动）；`how=slot` 写进 exe（没有槽的老 exe 回 409）。地址由网页带上来，默认 `location.origin`，可以改。只有系统管理员能导。
  - exe 来源：`CLIENT_EXE_DIR`（默认 `./data/client-exe`）或项目根的「发布」文件夹（机房版）里有 exe 就用本地的；否则取 GitHub 最新正式版的附件（不含机房版），缓存在 `data/client-cache/<版本>/`。
  - 读写规则和 `desktop/client/slot.py` 一致，`tests/test_client_exe.py` 守着。
- `发版.py` 默认不再烤地址（`SERVER = ""`），发布说明改成让各学校从自己的平台导出。

## 验证

后端反馈测试通过：原来 2.23.0 的两条换成置顶的四条，覆盖只显示置顶、只有管理员能置顶、只能置顶公开的、撤下后消失、最多 5 条、到期消失。打字新增 2 条测试，覆盖新档位和老配置的兼容。服务端导出新增 5 条测试，学生端地址槽新增 5 条测试。真打了一个 4.15.0 的 64 位 exe，从本地后端两种方式各导出一次再跑自检：「写进 exe」那个报告「网站写入 https://exam.school-test.cn:8443」，「改文件名」那个报告「文件名 192.168.10.20:3315」，两个都是最终连的地址。前端构建通过。浏览器里验证过：组卷页和学生页顶上都显示置顶黄条；反馈页置顶、取消置顶后黄条立即跟着变；/dazi 里难度选困难带出 20 分钟、选中等带出 10 分钟、默认简单带出 5 分钟。
