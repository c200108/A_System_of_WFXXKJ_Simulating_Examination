# 教师端 APP 5.0.0 —— 教师端安卓 APP（原生）

发布：2026-10-09

新开一条产品线：**5.x = 教师端安卓 APP**（2.x 平台网页、3.x 仿真环境、4.x 学生桌面端）。

## 这次解决了什么

老师想在手机上组卷、发考试、看成绩、批操作题，以前只能用手机浏览器开电脑版网页：菜单挤出屏幕、
表格要左右拖、对话框比屏幕还宽，导出的 Excel 下不下来；令牌 12 小时过期，早上登一次下午就被踢回登录页。

## 怎么做的

### 原生 APP，不套网页

界面全部用安卓原生控件画，不打开网页；功能和教师端网页一一对应，数据走网页同一套 `/api`、同一个教师令牌。
手机上的交互按 APP 习惯重新设计：列表是卡片、点进详情页、新建编辑用底部弹层、长按多选批量操作、
右下角主按钮、下拉刷新、滑到底自动加载。

**屏幕适配**按窗口宽度分档（不看是不是平板，分屏变窄也自动跟着变）：
- < 600dp：底部标签栏，单列；
- 600–839dp：左侧导航栏，列表两列，表单字段并排；
- ≥ 840dp：列表三列，详情页左右分栏，表单居中限宽。

转屏、折叠屏展开、分屏改大小不重建页面，正在填的表单不会丢。支持跟随系统 / 浅色 / 深色。

**模块化**（Gradle 多模块）：`core` 放网络、会话、界面组件和全部资源；组卷、题库、考试、打字、学生、我的
各是一个独立模块，互相不依赖。底部五个标签：组卷 / 题库（题库管理、批量导入、仿真操作题）/
考试（考试管理、打字学情、练习文本）/ 学生（学生账号、班级）/ 我的（我的账号、账号管理、需求反馈、
更新日志、设置、关于）。

**包小**：只用系统自带组件（没有 AndroidX、没有第三方库），图标是矢量图，二维码、图表都是自己画的，
安装包约 450 KB。

**手机上做不了的**：仿真操作题里 Windows 操作、WPS 文字两类的环境布置和标准答案录制，要在模拟的
XP 桌面里拖拽、右键、用 WPS 工具栏排版，手机屏幕上没法用。APP 里说明原因、给出电脑端地址
（可复制或分享到电脑）；查看环境、改名称和检查点、试判、删除在 APP 里都能做。网页编程类仿真题
可以直接在手机上改代码生成检查点。

### 通讯：前台心跳续期，不用长连接

- **为什么不用 WebSocket**：系统里没有需要服务器主动推给老师的东西。长连接会让手机一直醒着、
  耗电，服务器要多维持一堆连接，nginx 还得另配升级头。
- **心跳**：`POST /api/app/session`，APP 在前台时每 5 分钟一次（间隔由服务器下发，
  `heartbeat_seconds`）。退到后台立刻停，回到前台马上补一次。一次一两百字节。
- **续期**：令牌用掉四分之一寿命就换一张新的，只要隔三差五打开过 APP，就不会过期。
- **过期兜底**：令牌真过期了，用保存的账号密码在后台重新登录。密码只在勾了「记住密码」时保存，
  用 Android Keystore 的 AES-GCM 密钥加密（密钥导不出、卸载即删）。任何接口回 401 也会触发这一步，
  然后重发原请求。只有密码被改、账号被停用才回登录页。
- **断网**：心跳失败按 5/10/20/40/60 秒退避重试，系统报告网络恢复时立即重试；断开期间顶部一条提示，
  点一下立即重试，恢复后收起。连不上的是外链图片这类别的网站时不算断开。
- **认服务器**：`GET /api/app/info`（公开），返回 `app: "wfxxkj-exam"`、协议版本、平台名称。
  登录前先调它，地址填错能当场说清楚。5.0 以前的服务器没有这两个接口：APP 退回去读 `/api/config`
  认服务器、用 `/api/auth/me` 当心跳，能用，只是没有自动续期。

### 文件

导出的 Excel、考试包、学生网页存进手机「下载/教学平台」（MediaStore，不用存储权限），可直接打开或分享。
试卷、样卷、成绩分析走系统打印，可另存 PDF。上传 Excel、图片用系统文件选择器。

## 验证

- 后端 `tests/test_app_mobile.py`：info 公开且能认出本系统；心跳要教师令牌、学生令牌进不来；
  新令牌不换、用掉四分之一寿命的换新且新令牌能用；过期令牌不能续。
- 构建环境没有安卓 SDK，用 aapt + javac + retrolambda + dx 打出 APK 并签名；用 Robolectric
  （真实渲染）连本地后端逐页截图检查了手机竖屏，抽查了平板横屏和深色模式。
- **没有在真机上跑过**，装机检查清单见 `android/README.md`。

## 升级注意

- 服务器建议升到这一版（多了认服务器和心跳续期两个接口）。网页端界面没有变化。
- APP 怎么打包、怎么签名、怎么发给老师，见 [android/README.md](../../android/README.md)。
