# 服务端 2.17.2 —— 打字交成绩后显示全校排名

发布：2026-11-04

## 新增

网页打字（学生平台的打字练习、免登录的 /dazi 页面）：每次英文、中文打字交完成绩，成绩卡片上多一项「全校排名」——这次速度在全校**同一模块（英文 / 中文）、同一难度**里排第几、一共多少人；这次不是自己最好的一次时，顺带说出自己最好成绩和它的名次。

## 排名怎么算

- 每个学生只算自己**最好的一次**：练了 20 遍也只占一个名次，名次不会超过总人数；
- 名次 = 最好成绩比这次速度快的人数 + 1，一样快的并列；
- 认人：挂了账号的按账号；免登录手填的按「班级 + 姓名」；同一班级姓名既有挂账号又有没挂上的老记录，算一个人；同名不同班算两个人；
- **只是排名这样算**，每一次练习照样全部入库，老师的打字成绩页、导出、学情分析里一条不少；
- 键盘模块没有速度，不排名。

## 改了哪里

- `backend/app/routers/typing_train.py`：交成绩接口返回 `rank`、`rank_total`、`best_speed`、`best_rank`（`school_rank`）；
- `backend/app/schemas.py`：`TypingResultOut` 加这四个字段（可空，老前端不受影响）；
- `frontend/src/views/Typing.vue`、`frontend/src/views/student/Typing.vue`：成绩卡片显示排名。

## 验证

- 新增 `backend/tests/test_typing_rank.py`（一人多次只算最好、原始记录不少、并列、模块难度分榜、同名不同班、账号并老记录、键盘不排）；
- 浏览器里打完一段英文看过成绩卡片。
