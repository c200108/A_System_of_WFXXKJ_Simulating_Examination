# 学生端 4.10.0 —— 姓名登录版

发布：2026-10-08（同期平台 2.13.0，详见 [2.13.0.md](2.13.0.md)）

另打一版学生端：**账号填中文姓名，初始密码统一 123456**。普通版（学号 + 学号）照旧，两版并存。

- 打包开关 `build.py --name-login`，写进 `client/_build.py` 的 `NAME_LOGIN`；文件名多一个「姓名登录」，
  如 `考试客户端-姓名登录-32位-内置运行库@111.170.33.3_3315.exe`。开发时 `python exam_client.py --name-login`。
  做成开关而不是另抄一份客户端：两版只差登录页那几个字和调哪个接口。
- 登录页第二栏变成「姓　　名」，提示「重名的同学填学号」；调 `POST /api/student/login-by-name`。
- 首页「修改密码」的说明写「初始密码是 123456」；原密码填 123456 就行（服务端认）。
- 离线开考按考试包名单里的姓名找人，找到后交卷带的是他的学号；名单里重名时提示改填学号。
- 自检报告多一行「登录方式」，装机时一眼看出拿到的是哪一版。
- `_build.py` 留在源码里：打完姓名登录版，`build.py` 会把 `NAME_LOGIN` 拨回 False，
  不然之后直接跑源码、跑测试都悄悄变成姓名登录版。
- `发版.py` 一次打八个：原来四个 + 姓名登录版四个（附件名带 `name-login-`）。

## 验证

- `tests/test_ui.py` 姓名登录版 6 条：登录页文案、姓名 + 123456 登进去、学号那套初始密码不认、
  重名提示改填学号、改密码后用新密码、离线按姓名找人。
- `tests/test_single_exe.py`：开关烤得进去读得回来；文件名和普通版分得开。
- 打出来的八个 exe 都过了自检。

## 升级注意

服务端要先升到 2.13.0（没有 `/api/student/login-by-name` 时姓名登录版登不上）。
