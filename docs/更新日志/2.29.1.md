# 服务端 2.29.1 / 学生端 4.19.0 —— 计时修复、到点强制交卷、错题导出、日期框宽度

发布：2026-11-26

## 剩余时间（`frontend/src/submitGate.js`）

- 开考时间记在 localStorage `examStartedAt:<考试>`，现在存 `{at, paper}`：paper 是这一套卷子的标识
  （网页链接开了乱序时是服务端给的 draw，学生平台是空串，卷子按「考试 + 学号」固定）。
- `start(paperKey)` 重新计时的情况：没有记录、记录在未来、记录的卷子和这次不同、记录超过「时长 + 10 分钟」
  （上次没交完的老记录）。2.29.0 及以前存的是一个数字，没有卷子标识，读到就作废、重新计时。
- 临时保存后刷新是同一套（draw 相同），接着计时；换了卷子重新计时。
- `late`：剩不到 180 秒；`timeUp`：剩 0。

## 到点强制交卷（`views/Take.vue`、`views/student/ExamTake.vue`）

- `watch(timeUp)` → `submit(true)`：不过交卷门槛、不弹「还有几题没做」、不拦开发者工具；开着的确认框 `ElMessageBox.close()`。
- 到点后作答控件全部禁用。链接答题没选班级 / 没填姓名的弹窗说明，填好点「交卷」直接交（`timeUp` 时手动交卷也走强制路径）。
- 底栏常驻的门槛提示去掉；门槛照旧，点「交卷」不满足时 `ElMessage` 提示原因。
- 学生端 exe（`desktop/client/exam_ui.py`）：`tick()` 到 0 不再 `messagebox.showinfo`，直接 `do_submit(auto=True)`；
  最后 3 分钟倒计时底色变红（`RED_CLOCK`）。

## 错得最多的题

- `question_stats` 返回完整题干（以前截 60 字）。
- 成绩页列正确率最低的 20 道（只列有人作答的；同正确率作答人多的在前），题干完整、折行，表格 `max-height` 460 可滚动，多一列「作答」。
- `GET /api/exams/{id}/hardest.xlsx?limit=`：全部有人作答的客观题按正确率从低到高；列：序号、题型、知识范围、题干、选项 A～F、
  正确答案（字母 + 内容）、作答人数、答对、答错、未作答、正确率、答错的人最多选（前两名）。

## 日期范围框

- `App.vue` 全局：`.el-range-editor` `flex: none`、宽 300px（datetimerange 340px）、`max-width: 100%`。
- 考试成绩页：「交卷时间起 至 交卷时间止」。
