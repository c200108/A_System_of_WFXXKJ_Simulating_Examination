# 服务端 2.19.1 —— 学生管理「重置密码」改成重置为 123456

发布：2026-11-05

## 修复

「学生 → 学生管理」的「重置密码」看起来不管用。原因：重置是把密码改成**各人的学号**，而学生登录页、学生端都写着「初始密码 123456」，学生照着填 123456 就登不上（学号版学生端尤其明显），老师以为没生效。

- 批量「重置密码」统一重置成 **123456**（`students.RESET_PASSWORD`），学号登录（`/api/student/login`）、姓名登录（`/api/student/login-by-name`）、学生网页都认；原来的密码立即失效。
- 确认框写明「把这 N 个学生的密码重置成初始密码 123456？」，完成提示「已把 N 个账号的密码重置成 123456」。
- 编辑学生的弹窗里新增「重置为 123456」按钮，点了确认后当场生效，不用再点保存；密码框提示改成「留空则不改密码，或填一个新密码」。
- 重置后学生用 123456 当原密码就能改新密码（`still_initial` 认 123456）。
- 新建学生不填密码时仍以学号作初始密码，学号登录不认 123456 的老规矩不变（只有被重置过的才是 123456）。

## 验证

`backend/tests/test_students.py`（批量重置后 123456 能登、旧密码失效；编辑里重置为 123456 后学号 / 姓名登录都认；重置后用 123456 改新密码）。本机起服务端和网页实际点过批量重置、编辑框里的「重置为 123456」，学号登录、姓名登录用 123456 都返回 200，旧密码 400。
