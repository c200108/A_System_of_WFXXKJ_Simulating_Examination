# 2.10.1 —— 老师只管自己班的学生；服务器上配图不显示

发布：2026-09-24

## 一、学生管理按班隔离

管理员照旧看全校。老师只看得到、只管得着**自己名下的班**（「班级」页面里分到自己的班）的
学生，接口一层一层都收窄了（`routers/students.py` 的 `_scope` / `_mine` / `_own_class`）：

| | 老师 |
|---|---|
| 列表、导出、班级筛选下拉 | 只有自己的班 |
| 添加一个 | 必须选自己的班（不能建"未分班"的 —— 建完自己就看不到了） |
| 修改、调班 | 只能改自己班的学生，只能在自己的几个班之间调 |
| 批量启用 / 停用 / 重置密码 / 删除 | 勾选里混进别的班的 id 一律不认 |
| 导入 Excel、粘贴名单 | 写着别人的班、或者没写班又没选默认班的行导不进来，其余照常导；提示里列出自己的班 |
| 导入模板「可用班级」 | 只列自己的班 |

别的班的学生，老师连"有这个人"都看不出来：改、删一律回 404。名下还没有班的老师看到的是空
列表和一句"请管理员把班分给你"。班级管理本身没动。

老数据里 class_id 为空、只写着班级名的学生，名字和自己的班对得上的也算自己班的。

## 二、服务器上配图不显示，只有 exe 正常

题库、组卷、网页答题里的配图全裂。前端容器的 nginx 里有一条「按扩展名缓存静态文件」的正则
location（`\.(js|css|…|png|jpg|jpeg|gif|ico)$`），**正则 location 的优先级比普通前缀高**，
`/uploads/images/x.jpg` 先被它截走，去前端自己的 html 目录里找，找不到就 404。
exe 的图是打在考试包里、走 `/api` 下来的，所以只有它正常。

改成 `location ^~ /uploads/`（前缀匹配上就不再看正则），`/api/` 也顺手加上 `^~`。
`tests/test_nginx_conf.py` 守着：在旧配置上这两条测试是红的。

机房版没有 nginx，配图由后端直接发，不受影响（实测 200 image/jpeg）。

## 三、机房版：GitHub 下载的包里没有学生端 exe

「发布」文件夹原来不进仓库（exe 放在 Releases 上），从 GitHub 下 ZIP 的人拿到的是一个没有
exe 的机房版，「改学生端地址.bat」无文件可改。现在仓库里带两个内置运行库的学生端（4.8.0，
程序本身没变），**不再烤进线上服务器的地址**：改名后连机房教师机，不改名就让学生在登录页填。
