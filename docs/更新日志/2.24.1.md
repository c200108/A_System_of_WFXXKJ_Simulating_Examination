# 服务端 2.24.1 —— 一键更新查不到版本、每次都直接下载

发布：2026-11-19

## 原因

主机助手（`scripts/host-agent.sh`）由 systemd 以 root 拉起，服务进程**没有 HOME 环境变量**。git 找不到 `~/.gitconfig`，
`setup-github-cn.sh` 配在 `/root/.gitconfig` 里的加速（`url.<加速地址>.insteadOf https://github.com/`）就不生效，
`check_latest` 里问提交号的 `git ls-remote` 只能直连 github.com；后面两条退路（api.github.com、raw.githubusercontent.com）
在国内服务器上也常连不上，于是每次都是「查不到 GitHub 上的版本，照常下载更新」。下载那步（`download_zip`）
是自己读配置文件拼加速地址的，所以一直能下下来；在命令行里手动 `git clone` 有 HOME，所以也一直正常。

## 修复

- 脚本开头没有 HOME 就按当前用户（root）补上，git 就能读到加速配置；
- `remote_versions`：原来写成 `curl … | seed_versions && return 0`，curl 失败了管道照样返回成功，得到一个空版本。
  改成先存下来，非空才算问到。

## 生效时间

主机助手是从项目目录里跑的：这一版要先装上（再点一次「一键更新」，这次仍会直接下载），之后的更新才会先比版本。
