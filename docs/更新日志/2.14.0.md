# 2.14.0 —— 拼音登录、班长组长、交卷门槛

发布：2026-10-09（同期学生端 4.11.0，详见 [4.11.0.md](4.11.0.md)）

## 要什么

- 教师端学生名单：导入的名单按姓名自动出拼音全拼，单独存一列；
- 班级管理里能设每个班的班长、组长；
- 学生登录改用姓名拼音全拼，密码默认 123456；登录页先选班级（2026-10-10 改：不再用「拼音 + 年级班级」
  如 xingming0801 区分重名，教师端也不再存、不再显示这种账号）；
- 考试时间过了三分之二、并且答完三分之二的题才允许交卷。

## 怎么做的

**拼音**（`app/services/pinyin.py`，依赖 pypinyin，纯 Python）

- 全拼、小写、无声调、无空格，ü 写成 v（吕 → lv），「·」和符号去掉；
- 姓氏多音字按姓氏读（单 shan、曾 zeng、解 xie、仇 qiu、区 ou、朴 piao …，复姓尉迟、长孙等），
  只改姓，名照常读；名字里的多音字程序猜不准，老师在「编辑学生」里手改；
- `students` 表加 `pinyin`、`class_role` 两列（迁移 0017），迁移时按姓名给已有学生补齐拼音；
- 建账号（单个、粘贴、上传表格）时自动生成；改姓名时重算；老师清空拼音 = 按姓名重算。

**登录**：登录页先选班级，再填拼音全拼 + 密码。

- 班级下拉来自新接口 `GET /api/student/classes`（不用登录），列出有在用学生的班级；
- `POST /api/student/login-by-name?name=&password=&class_id=`：选了班级就只在这个班里按拼音找人。
  不带 `class_id`（4.10.0 的老 exe）时全校只有一位在用学生是这个拼音才认，重了提示先选班级；
- 同一个班里拼音还重（两个张伟在一个班）：提示改填学号；停用的学生不算重名；
- 账号栏依次认：学号（不看班级）→ 拼音 → 中文姓名。不再有「拼音 + 年级班级」这种账号；
- 密码：没改过密码的账号只认 123456；改过的认新密码；填学号时学号那个老初始密码也认；
- 学号登录 `POST /api/student/login` 不变。

学生网页登录页换成「班级 + 姓名拼音 + 密码」，记住上次选的班级；学生首页显示本人的拼音。
教师端学生列表加「拼音」「班干部」两列，关键字也能搜拼音；导出的 Excel 前四列不变（还能导回去），
后面加拼音、班干部；导入模板的说明页写了拼音登录规则。考试包名单带上每人的班级和拼音，给学生端离线开考用。

**班干部**：`PATCH /api/students/{id}` 加 `class_role`（班长 / 组长 / 空）。一个班一位班长，设新班长时原来那位
自动卸任；组长不限人数；调班时清掉；没分班的不能设。班级详情抽屉里名单多一列下拉，顶部列出班长和组长。
权限和改学生资料一样：老师只能设自己班的。

**交卷门槛**（`frontend/src/submitGate.js`，学生平台考试页和链接答题页共用）：考试时间过 2/3、且已答题数 ≥ 总题数 × 2/3
（都向上取整）才放行。网页答题原来没有倒计时，开考时间记在浏览器 localStorage（按考试分开），刷新不重新计时。
不够时按钮旁边一直显示还差几题、还要等多久。门槛只在客户端：服务端分不出「时间到自动交」和「学生手动交」，
在服务端卡题数会把时间到时没答够的卷子挡掉。

## 验证

`backend/tests/test_student_pinyin.py` 13 条：拼音规则（多音姓、复姓、ü、少数民族名字）、拼音登录、
班级下拉不用登录、重名按班级分开、不选班级时重名提示选班、停用的不算重名、同班重名只能用学号、老师改拼音、改名重算、导入自动生成、导出列、班干部
（一位班长、换人卸任、非法值、调班清掉）、中文姓名照样能登、考试包名单带拼音。全部后端测试通过。

## 升级注意

- **有数据库迁移（0017）**，并新增依赖 pypinyin。服务器 `git pull && sudo docker compose up -d --build`
  （镜像重建时装依赖、启动时跑迁移并补拼音）；
- 名字里有多音字的学生，升级后请老师在学生列表里看一眼拼音，不对的点「编辑」改；
- 学生要在班级里才能用拼音登录：还没分班的学生请先在学生列表里分好班，或者用学号登录。
