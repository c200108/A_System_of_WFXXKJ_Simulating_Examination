# 2.14.0 —— 先选班级再登录、班长组长、交卷门槛

发布：2026-10-12（同期学生端 4.11.0，详见 [4.11.0.md](4.11.0.md)）

## 要什么

- 学生登录改成「班级 + 汉字姓名」，密码默认 123456；登录页要先选班级；
- 班级管理里能设每个班的班长、组长；
- 考试时间过了三分之二、并且答完三分之二的题才允许交卷。

（过程：10-09 曾做过「姓名拼音全拼登录」，10-12 决定不用拼音，拼音生成和拼音登录整块去掉，改回汉字姓名。
`students.pinyin` 列由迁移 0018 删除；没跑过 0017 的库两步一起跑完，结果一样。）

## 怎么做的

**登录**：登录页先选班级，再填汉字姓名 + 密码。

- 班级下拉来自新接口 `GET /api/student/classes`（不用登录），列出有在用学生的班级；
- `POST /api/student/login-by-name?name=&password=&class_id=`：选了班级就只在这个班里按姓名找人。
  不带 `class_id`（4.10.0 的老 exe）时全校找，同名的几位里谁的密码对上就是谁，都用着 123456 时提示先选班级；
- 同一个班里重名：提示改填学号；停用的学生不算重名；
- 账号栏依次认：学号（不看班级）→ 汉字姓名；
- 密码：没改过密码的账号只认 123456；改过的认新密码；填学号时学号那个老初始密码也认；
- 学号登录 `POST /api/student/login` 不变。

学生网页登录页换成「班级 + 姓名 + 密码」，记住上次选的班级。考试包名单带每人的学号、姓名、班级，给学生端离线开考用。

**班干部**：`students` 表加 `class_role`（迁移 0017），`PATCH /api/students/{id}` 加 `class_role`（班长 / 组长 / 空）。
一个班一位班长，设新班长时原来那位自动卸任；组长不限人数；调班时清掉；没分班的不能设。班级详情抽屉里名单多一列下拉，
顶部列出班长和组长。教师端学生列表加「班干部」一列，导出的 Excel 后面加班干部列。权限和改学生资料一样：老师只能设自己班的。

**交卷门槛**（`frontend/src/submitGate.js`，学生平台考试页和链接答题页共用）：考试时间过 2/3、且已答题数 ≥ 总题数 × 2/3
（都向上取整）才放行。网页答题原来没有倒计时，开考时间记在浏览器 localStorage（按考试分开），刷新不重新计时。
不够时按钮旁边一直显示还差几题、还要等多久。门槛只在客户端：服务端分不出「时间到自动交」和「学生手动交」，
在服务端卡题数会把时间到时没答够的卷子挡掉。

## 验证

`backend/tests/test_student_class_login.py`：班级 + 姓名登录、班级下拉不用登录、不同班同名分开、不选班级时同名提示选班、
同班同名只能用学号、停用的不算重名、导出列、考试包名单、班干部（一位班长、换人卸任、非法值、调班清掉）。
迁移测试（含 0017→0018）和全部后端测试通过。

## 升级注意

- **有数据库迁移（0017、0018）**。服务器 `git pull && sudo docker compose up -d --build`；
- 学生要在班级里才能用「班级 + 姓名」登录：还没分班的学生请先在学生列表里分好班，或者让他们用学号登录。
