# 2.14.0 —— 学生先选班级再用姓名登录、班长组长、交卷门槛

发布：2026-10-09（同期学生端 4.11.0，详见 [4.11.0.md](4.11.0.md)）

## 要什么

- 学生登录：先选班级，再填中文姓名，密码默认 123456；
- 班级管理里能设每个班的班长、组长；
- 考试时间过了三分之二、并且答完三分之二的题才允许交卷。

（起草时曾做过「姓名拼音全拼登录」，教师端按姓名自动生成拼音；发布前改回中文姓名，拼音的生成、存储、登录都去掉了。）

## 怎么做的

**登录**：登录页先选班级，再填中文姓名 + 密码。

- 班级下拉来自新接口 `GET /api/student/classes`（不用登录），列出有在用学生的班级；
- `POST /api/student/login-by-name?name=&password=&class_id=`：选了班级就只在这个班里按姓名找人；
  不带 `class_id`（4.10.0 的老 exe）时在全校找；
- 账号栏先认学号（不看班级），再认中文姓名；
- 同一个班里重名：谁的密码对上就是谁；都还用着 123456 分不出来时，提示改填学号；
- 密码：没改过密码的账号只认 123456；改过的认新密码；填学号时学号那个老初始密码也认；
- 学号登录 `POST /api/student/login` 不变。

学生网页登录页换成「班级 + 姓名 + 密码」，记住上次选的班级。考试包名单带每人的班级，给学生端离线开考用。

**班干部**：`students` 表加 `class_role` 一列（迁移 0017）。`PATCH /api/students/{id}` 加 `class_role`
（班长 / 组长 / 空）。一个班一位班长，设新班长时原来那位自动卸任；组长不限人数；调班时清掉；没分班的不能设。
班级详情抽屉里名单多一列下拉，顶部列出班长和组长；学生列表、导出的 Excel 加「班干部」一列（前四列不变，还能导回去）。
权限和改学生资料一样：老师只能设自己班的。

**交卷门槛**（`frontend/src/submitGate.js`，学生平台考试页和链接答题页共用）：考试时间过 2/3、且已答题数 ≥ 总题数 × 2/3
（都向上取整）才放行。网页答题原来没有倒计时，开考时间记在浏览器 localStorage（按考试分开），刷新不重新计时。
不够时按钮旁边一直显示还差几题、还要等多久。门槛只在客户端：服务端分不出「时间到自动交」和「学生手动交」，
在服务端卡题数会把时间到时没答够的卷子挡掉。

## 验证

`backend/tests/test_student_class_login.py`：班级 + 姓名登录、班级下拉不用登录、重名按班级分开、同班重名提示学号、
停用的不算、学号照样能登、不带班级的老客户端、班干部（一位班长、换人卸任、非法值、调班清掉）、导出列。全部后端测试通过。

## 升级注意

- **有数据库迁移（0017 加班干部列；0018 删掉起草版留下的拼音列，没有就跳过）**。服务器
  `git pull && sudo docker compose up -d --build`（启动时跑迁移）；
- 学生要在班级里才能按班级登录：还没分班的学生请先在学生列表里分好班，或者用学号登录。
