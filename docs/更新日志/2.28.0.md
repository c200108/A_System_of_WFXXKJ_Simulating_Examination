# 服务端 2.28.0 —— 每次取卷重抽、临时保存、交卷规则、排名、发放班级按年级选、防作弊

发布：2026-11-25（学生端 exe 本期不变）

## 每次取卷重抽（`services/exam_rules.py`，迁移 0032）

只对**网页链接答题**（`GET /api/take/{token}`），而且试卷开了「选择判断题乱序」时：

- **按题型组的卷子**：每次取卷，选择、判断、填空题按原卷每种题型的数量，从「同题型 + 原卷里这种题出现过的知识范围」
  的题库里用 `SystemRandom` 重新抽（`paper.type_pool`，只抽有答案、没停用的题）；测评卷的范围只有本年级测评题，
  所以只在本年级里抽。题库不够的位置用原卷的题补。操作题不动。
- **六大题的卷子**：每个大题的题有各自的限定（范围、长题干、仿真类别），不重抽，只靠答题页每次换随机种子重新打乱题序和选项。
- 重抽出来的一套存成一行 `exam_draws`（`key` 随机 16 位，`items_json` 记题目 id、所属大题、分值），取卷返回 `draw`。
  交卷带上 `draw`，服务端按这一套判分，答卷记 `exam_submissions.draw_key`；成绩详情、分析、导出按每份答卷自己那一套算。
  两周前生成、没人交过的抽卷在下一次重抽时顺手清掉。
- 带 `?draw=key` 取卷就原样给回那一套（临时保存后刷新用）；key 不对（别的考试的、不存在的）就当没带，重抽。
- 学生平台（`/api/student/exams/{id}`）题序按「考试 + 学号」固定；学生端 exe 走 `/api/desk/exam` 拿原卷、交卷不带 `draw`，
  按原卷判分 —— 两者都不重抽。

## 临时保存

- 网页链接答题：存进浏览器 `localStorage`（`take-save-{token}`：draw、乱序种子、作答、班级姓名、时间）。
  刷新时带着 draw 取卷，draw 对得上就把种子和作答放回去，题目、选项顺序、已选内容都不变。交卷成功删掉。
- 学生平台答题：存 `exam-save-{考试}-{学号}`，只存作答（题序本来就固定）。

## 交卷规则（`check_submit`）

- `exams.max_attempts`：允许重考时最多交几次（0 = 不限）；不允许重考就是 1 次。超了 409。
- `exams.rate_window` / `rate_max`：几分钟内最多交几次（任一为 0 = 不限）。超了 429：
  「提交次数过多：每 5 分钟最多交 2 次。请等 3 分 20 秒后再交卷，作答内容都还在。」答题页弹窗，不刷新、不清空。
- 「一个人」按能认出来的最准的算：学生账号 → 学号 → 班级 + 姓名。三个交卷入口口径一致。
- 考试列表每行「规则」按钮改这几项，发布时也能设。

## 单场考试时长

- `exams.duration`（空 = 用试卷上的）。成绩详情 →「样卷」顶上改，或「恢复试卷上的 X 分钟」。
  取卷（网页、学生平台、exe）都用 `exam_duration(exam)`。

## 排名、交卷人数

- 交卷返回 `rank`、`rank_total`：每人（同上的认人口径）取最高分，按分数排第几，并列同名次。
- `ExamOut.student_count`、统计里的 `student_count`：交卷人数；`submission_count` 是份数。
  成绩详情 KPI 分开写「交卷人数」「交卷份数」，列表「交卷」一栏人数和份数不同时写「X 人 / Y 份」。

## 分值（`paper.even_scores`）

- 按题型组卷的卷子：100 分按题数平分成整数，除不尽的余数给前面几题各加 1 分（40 题 → 前 20 题 3 分、后 20 题 2 分）。
  组卷时写进卷子；`load_items` 取题时也重算，所以**已经发布的老考试**不用重发，跟着网站版本自动用新分值。六大题卷子不变。
- 大题标题写「每题 X 分」或「每题 X～Y 分，共 Z 分」（`frontend/src/scoreNote.js`），组卷页、样卷、答题页一致。

## 发放班级（`components/ClassPicker.vue`）

- 每个年级一行：年级前的勾选框一键全选 / 取消（部分选中显示半选），后面每个班一个小方块；底部「已选 N 个班 · 清空」。
  一个都不选 = 全体学生。发布考试、「加班级」两处共用。

## 样卷、分析入口

- 样卷改成组卷页的版式（标题、学校 · 时长 · 满分 · 编号、大题标题、答案、来源标签）。
- 考试列表行上的「分析」按钮去掉，成绩分析从成绩详情里进。

## 删除存档试卷不连带考试

- 迁移 0032：`papers.is_hidden`。删除试卷时：有考试用它 → 只隐藏（存档列表、按题型列表里看不到），考试、成绩照常；
  没有 → 照旧进回收站。接口多返回 `kept_exams`，组卷页提示「已发布的 N 场考试保留」。

## 安全检查

- 题目发给学生时从不带答案（取卷白名单测试覆盖），判分只在服务器做；交卷只认服务端存的那一套（draw），改不了题、改不了分值。
- 防爆破（`services/throttle`）：同一 IP 同一场考试每分钟最多取卷 30 次；交卷核对名单失败，同一 IP 10 分钟超过 20 次暂时拒收；
  交卷频率见上。教师登录原有的失败锁定不变。
- 答题页（`frontend/src/examGuard.js`）：考试期间屏蔽 F12、Ctrl+Shift+I/J/C/K、Ctrl+U、Ctrl+S、右键菜单；
  用 `debugger` 计时检测开发者工具，开着就盖住整页、不让交卷，关掉自动恢复。
  作答组件开 `guard`：脚本（控制台）造出来的点击、输入事件（`isTrusted` 为 false）不算作答，界面也撤回。
- 前端是 Vite 生产构建，代码压缩混淆、不带 source map。
- 说明：浏览器里的防护只能挡住大部分学生，挡不住专门绕过的人；真正的保证是答案不下发、服务端判分和频率限制。
