# 教师端 APP 5.3.0 —— 补上网页端 2.23～2.25 的新功能

发布：2026-11-23

对照网页端 5.2.1 之后的改动（服务端 2.23.0～2.25.1），把老师在网页上能用、APP 里还没有的补上；已有的功能不动。

## 新增

- **课堂签到 + 在线座次多工作表**（服务端 2.24.0，网页 `CheckinBox.vue`）：在线座次页工具栏下面一栏 `CheckinBar`。
  - 本班老师 / 管理员选 1～10 分钟发起；签到中显示倒计时、已签 / 应到、缺勤，「详情」列未签到（标出已登录的）、已签座号和时间、已登录的学生；可提前结束。
  - 和网页一样短轮询：签到进行中每 2 秒问 `/checkins/current`，版本号变了才重读签到那张表；页面被盖住、签到结束就停。
  - 工作表标签：`sheet1`（`/seat-sheet`）+ 附加工作表（`/seat-tabs`）。切换前有没保存的改动会先问；附加表保存走 `PUT /seat-tabs/{id}`，长按标签或菜单「删除这张工作表」。正看着签到表又没手动改过，学生签上来自动重读。
- **置顶提醒**（服务端 2.24.0，网页 `FeedbackNews.vue`）：`PinnedNews` 放在主界面顶栏下面，每个页面都有；切页面时最多一分钟刷新一次，管理员置顶 / 取消后马上刷新；点 × 关掉的记在本机（`feedback-pins`）。需求反馈卡片显示「置顶到…」，管理员「⋮」菜单里置顶（不限期 / 1～30 天）、取消置顶。
- **个人云盘**（服务端 2.25.0）：
  - 「我的 → 个人云盘」（`CloudScreen`）：用量、超额提示、云盘网址复制、登录名说明、单独设云盘密码 / 改回一致。服务器没启用时「我的」里不显示这一行。
  - 「打开个人云盘」（`CloudWebScreen`）：云盘是 OpenList 自己的网页，用内嵌浏览器打开。先 `POST /cloud/open` 换令牌，用 `loadDataWithBaseURL` 以服务器为源把令牌写进 `localStorage['wfxxcloud:token']` 再跳 `/cloud/`，和网页端一样免登录。上传走系统文件选择器（没选也要答复，主界面 `pickFiles` 取消时回调空列表，`Screen.pickFiles` 照旧滤掉空的），下载交给系统下载管理。离开时清掉内嵌浏览器存储。
  - 管理员「账号管理 → 个人云盘」（`CloudAdminScreen`）：服务状态、磁盘、总容量设置、已分配 / 实际已用、每位老师分配 / 调整 / 收回。
- **API 多选批量**（服务端 2.23.0）：长按卡片或「多选」，批量恢复 / 暂停接收、删除，管理员批量转给其他老师（`POST /data-apis/bulk`）。
- **数据备份与系统更新**：显示本机服务端版本和提交号；一键更新已经是最新时提示「没有下载任何东西」；新增「下载学生客户端」（服务端 2.24.0 `/system/clients`）：填学生连的地址（默认 APP 登录的服务器地址），选写进 exe 或改文件名，存到「下载/教学平台」。

## 没做的

- 打字计分会话、限时档位（2.23.1、2.24.x）：APP 没有打字练习，只看成绩和分析，不受影响。
- 云盘的文件管理界面：用 OpenList 自己的网页，不重做原生版。

## 验证

云端用 javac 对全部模块做了编译检查（Robolectric android-all API 34）。待用户电脑正式签名打包、真机试用。
