# 2.15.0 —— 练习文本加「主题」

发布：2026-11-02

## 这次解决了什么

练习文本是从同一难度里随机抽几段拼成一篇的。文本越加越多、话题越来越杂以后，一篇里前一句讲键盘指法、
后一句讲人工智能，读起来不连贯；老师也没法按话题（比如这周讲网络安全）安排练习内容。

## 怎么做的

- 新表 `typing_themes`（名称、是否启用、排序、是否内置），迁移 0021 建一个内置主题「信息生活」，
  升级前的所有文本（内置的、老师加的、导入的）都归它；`typing_texts.theme_id` 记文本属于哪个主题，
  为空时也当「信息生活」算。
- **取文本**（`services/typing_texts.py: build_passage`，网页端和 exe 共用的 `/api/typing/passage`）：
  1. 候选主题 = 启用的、并且这个语言 + 难度下有启用文本的主题；
  2. 候选里**等概率**挑一个（不按段数加权，段多的主题不会老被抽到）；
  3. 只在这个主题里洗牌抽几段拼起来；不够就有几段拼几段，**不拿别的主题凑**。
  随机数用系统熵，每次请求各自随机，一个机房六十台同时取也是各取各的。
- **老师端**（题库 → 练习文本）：主题列表（开关、各难度段数、查看、改名、删除）、新增主题；
  添加 / 编辑 / 上传 txt 时选主题；列表按主题筛选；勾选后「批量改主题」。至少保留一个启用的主题。
  删除主题要删除权，内置主题删不掉；删掉的主题进回收站，还原时文本接回原主题。
- 教师端安卓 APP 暂时不显示主题：APP 里新增的文本归「信息生活」，其余照常使用。

## 怎么验证的

后端新增 `tests/test_typing_themes.py`：迁移把老文本归到「信息生活」、120 次取文本从不跨主题、
两个主题被抽中的次数各占一半左右（段数 20 : 1 也一样）、停用的主题取不到、段数不够不拿别的主题凑、
至少保留一个启用、删主题后文本归回且回收站还原能接回、导入 / 编辑 / 批量改主题。
