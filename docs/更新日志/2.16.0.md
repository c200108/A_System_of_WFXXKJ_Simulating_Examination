# 服务端 2.16.0 —— 教师端「API」板块、学生学情

发布：2026-11-03

## 新增

1. **API 板块**（网页顶栏「API」）：老师新建 API（名称、描述、用途），拿到接收地址和写入密钥，
   自己做的教学网页把学生答题、自评、互评、问卷数据送过来。格式尽量都收，规范见 [API数据接入规范.md](../API数据接入规范.md)。
   每个 API 里：数据表单、来源网页、数据大图（可投屏）、接入说明、设置。
2. **各老师互不相通**：老师只看得到自己建的 API（管理员建的也看不到），管理员看全部、可按老师筛选、可转给另一位老师。
3. **学生学情**：学生名单「学情」一列，汇总考试成绩与排名、打字、教学网页数据。教学网页数据只算看的老师自己的 API。

## 数据库

迁移 0022：新表 `data_apis`、`data_records`、`data_record_items`。升级时自动建表，不动已有数据。

## 接口

- 教师端（教师令牌）：`/api/data-apis`（增删改查、`/records`、`/records/delete`、`/sources`、`/stats`、`/export`、`/test`、`/rotate-token`、`/transfer`）；
  `/api/students/{id}/insight`。
- 公开（各 API 自己的密钥）：`POST|GET /api/hook/{key}`、`/api/hook/{key}/records`、`/api/hook/{key}/summary`、`/api/hook/sdk.js`。
  跨域在 `main.py` 的 `HookCors` 里单独放行。

## 部署注意

- 接收地址按老师打开网页用的地址拼（和学生考试链接同一套规则）；服务器在 nginx 后面、老师用 localhost 打开时，
  在 `.env` 配 `PUBLIC_BASE_URL`。
- 配合教师端 APP 5.1.2 使用 APP 里的「API」标签和学生学情。
