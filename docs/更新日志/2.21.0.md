# 服务端 2.21.0 —— 在线座次：课堂日志、长按拖动换座、小组配色、右键加减分 / 班干部

发布：2026-11-06

## 新增

### 课堂日志（`components/ClassLogs.vue`，表 `class_logs`）

- 座次表右边独立一栏，便签样式（浅黄底、左边色条），和表格隔开一段、不连在一起。
- 「+ 新建」：日期默认今天、标题自动「第 N 次上机」，正文预先写好「请假 / 缺勤」「设备问题」「课堂情况」三行；能从本班名单里多选缺勤同学，点「写进去」接在「请假 / 缺勤：」后面。
- 每条显示日期 + 星期、标题、正文（照原样换行）、作者、最后修改时间；最新的在上面，可改可删。没保存就关面板先提醒。
- 接口：`GET/POST /api/classes/{id}/logs`、`PUT/DELETE /api/classes/{id}/logs/{lid}`。看谁都能看，写改删只给本班老师和管理员。
- 外键 `ON DELETE CASCADE` 跟着班：删班进回收站时一起拍快照，还原班级时日志也回来。

### 座位板交互（`components/seatBoard.js`、`SeatMenu.vue`、`SeatGroups.vue`）

表格本体仍是 Jspreadsheet（改字、样式、合并），上面加一层：**不碰格子的 style 属性**（表格库保存样式就是读 style 属性），小组底色、班干部图标、分数角标都靠 `data-*` 属性 + 生成的 CSS 显示，不会存进座次表、不会出现在导出 / 打印的格式里（打印、导出 Excel 另外按小组补底色）。

- **认人**：格子里写「姓名」或「学号 姓名」都认；重名只认「学号 姓名」那种写法。
- **长按拖动换座**：按住学生格子约 280 毫秒不动才抓起，按下后先动超过 6 像素就当普通框选。抓起时给表格库发一个 mouseup 结束它的框选，之后的移动 / 松开在 window 捕获阶段截下来。目标有学生互换、空格子搬过去、写着非学生文字（座位号、讲台）拒绝；Esc 取消。
- **小组**：存在座次表 JSON 里（`groups: [{id, name, color}]`、`groupOf: {学生 id: 组 id}`），跟着人走。工具栏「🎨 小组」：一键建 4 / 6 个组、改组名颜色（8 个淡色预设）、框选区域整批分组、清空分组；表格上方色块显示每组人数、组长、组内总分。导入 Excel 样式、清空表格时小组保留。
- **右键学生**（只给本班老师和管理员；右键其他格子仍是表格自带菜单）：+1 / +2 / +5 / −1 / −2、自定义分值和原因（「+3 回答问题」）、得分记录与撤销、设为班长 / 组长 / 取消（走 `PATCH /api/students/{id}`，一个班一位班长）、分到小组（子菜单）、从座位上移走。
- 格子标记：左上角 👑 班长 / ⭐ 组长，右下角分数（正绿负红），名字在正中不被挡；悬停格子 title 显示全称、小组、分数。

### 课堂加减分（表 `student_points`）

- 一笔一行（班级、学生、分值、原因、谁加的、时间），总分 = 相加；一次 −100 ~ 100、不能是 0；学生必须在这个班。
- 接口：`GET /api/classes/{id}/points`（总分 + 最近 200 条）、`POST`（返回新总分）、`DELETE /points/{pid}` 撤销。全部只给本班老师和管理员，别的老师看不到分数。
- 删班 / 删学生时记录跟着删（回收站能一起还原）。
- `GET /seat-sheet` 的学生名单多带 `class_role`。

## 修复

- 在线座次行高一直没生效：表格库把 `rows[i].height` 直接塞进 `style.height`，原来给的是数字没带 px，浏览器不认，所以导入的行高、保存后再打开都是默认行高。现在带上 px，按原表行高显示并保存。之前存过的座次表行高没存下来，重新导入一次 Excel 样式即可。
