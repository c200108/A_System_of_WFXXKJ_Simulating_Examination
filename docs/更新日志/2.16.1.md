# 服务端 2.16.1 —— API 板块的「AI 专用提示词」

发布：2026-11-03

## 解决什么问题

老师现在多半用 AI（豆包、DeepSeek、Kimi……）做课堂互动网页、问卷网页。只把接收地址和密钥给 AI，
AI 会自由发挥字段名（`studentName`、`totalScore`、`questions`……），平台虽然认一部分别名，但逐题正确率、
自评互评雷达图、互评矩阵都要按标准信封送才统计得出来；学生身份栏也常被漏掉，数据汇总不进学情。

现在每个 API 都能生成一段「AI 专用提示词」，老师整段发给 AI，最后写上要做什么网页就行。

## 怎么做的

- **后端统一生成**：`services/dataapi_prompt.py`，接口 `GET /api/data-apis/{id}/ai-prompt?base=`，返回 `{prompt, endpoint}`。
  网页版和 APP 共用一份，改提示词只改这一个文件。
- **`base` 由前端传**：后端在 nginx 后面看到的 Host 不带端口（会少 `:3315`），所以网页传 `studentLink('')`、
  APP 传连的服务器地址；不传或不像网址（不是 http/https）就退回 `_base_url`。
- **提示词内容**：任务说明（单文件 HTML）→ 这个 API 的名称、说明、用途、接收地址、写入密钥 → 一段原样照抄的提交代码
  （`WFXX` 配置 + `wfxxSend` / `wfxxFlush` / `wfxxBeacon`：client_id 去重、5xx/429/断网暂存到 localStorage、
  打开页面和重新联网时补发、sendBeacon 用 `_token`）→ 学生身份栏 → 按用途定制的字段规则和完整 JSON 例子 →
  回执和错误码怎么提示 → 页面要求 → 预留接口 → 注意事项 → 交付前自检清单 → 「老师的要求」占位。
- **跟着设置变**：开了「网页可读汇总」才附 `wfxxSummary()`；关联了班级就要求班级做成下拉、选项一字不改；
  设了来源网站白名单就写明网页必须放在哪些网站、file:// 会被拒；「只算最新一条」会写进提交说明；
  接收地址是 http 时提醒放在 https 网站上会被浏览器拦（混合内容）。
- **不放读取密钥**：提示词会发给 AI、贴进网页，读取密钥能看到全部数据。
- **预留接口**：`WFXX.ENDPOINT` 留空时网页照常能用，提交的数据暂存在本机，以后填上地址自动补交。

## 网页

- 新建 API 后跳到「接入说明」并自动弹出提示词（`?prompt=1`，弹完就从地址里去掉，刷新不再弹）。
- 「接入说明」最上面一张「AI 专用提示词」卡片：复制、预览。每次复制都重新取，改了设置、换了密钥也是最新的。

## 验证

- 后端测试：提示词只给自己的（别的老师 404）、不含读取密钥、按传入的 base 拼地址、坏 base 不用；
  五个用途各自把提示词里的例子 JSON 原样（换成名单里的学号）送进接收地址，都能入库、对上名单，
  逐题 / 维度统计和例子一致；开关汇总、关联班级、白名单、只算最新一条时提示词跟着变。
- 提交代码：五个用途生成的 JS 都过了 `node --check`；用 node 把 `wfxxSend` 真发到本机后端（201 入库）、
  模拟断网（暂存 1 条）、恢复后 `wfxxFlush` 补发（队列清空）、`wfxxSummary` 取到全班汇总。

## 升级注意

无数据库变化，重启服务即可。配合教师端 APP 5.1.3 在手机上复制提示词。
