# 学生端 4.12.0 —— 检查更新

发布：2026-11-02

## 这次解决了什么

学生端发新版以前只能把 exe 一台台拷到机房；机房里新旧 exe 混着用，「修好的问题怎么还在」十有八九是跑了旧的。

## 怎么做的

- 登录页底部「检查更新」：查**联网版公开仓库的 GitHub Releases**（Release 列表里挑 tag 是 v<数字> 的最新正式版，
  教师端 APP 的 teacher-v… 不算），按本机这份的联网版 / 机房版、位数、姓名登录版、内置运行库挑对应的附件下载。
  查版本、下载都走 GitHub，不占学校服务器带宽。
- 下载到 exe 同一个文件夹，校验大小、SHA-256 和 exe 文件头；把正在运行的旧版改名成 .old（运行中的 exe 能改名、
  不能覆盖），新版改成原来的名字并启动，下次启动删掉 .old。文件名（含 @地址）不变，不写注册表和用户目录。
- 只在点按钮时联网，考试中不查；两次至少隔 60 秒；整次查询 5 秒封顶（含 DNS），拿不到就提示「无法获取更新」。
- 机房版的 exe 也发在联网版这个 Release 里，附件名带 `exam-client-lan-` 前缀；版本号两版同一套。
- 自建更新源（后端 /api/client/update.json）预留、默认关着，见 desktop/README.md「自建更新源」。

本版同时包含此前没有单独发布的 4.11.1 的改动，见 [4.11.1.md](4.11.1.md)。

## 注意

机房里现有的旧 exe 没有「检查更新」按钮，这一版要手动换一次；之后的版本就能在登录页直接升级。
