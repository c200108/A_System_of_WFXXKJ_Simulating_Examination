# 教师端 APP 5.1.0 —— 检查更新、正式签名

发布：2026-11-02

## 这次解决了什么

APP 出了新版，以前只能把 apk 发到微信群里让老师自己装；老师不知道有没有新版，手机上的版本参差不齐。

## 怎么做的

### 「我的 → 检查更新」

- 点一下去 **联网版公开仓库的 GitHub Releases** 查：只看 tag 以 `teacher-v` 开头、不是草稿也不是预发布的
  最新一个（学生端 exe 的 Release 也在这个仓库里，tag 是 `v4.x`，不会混），附件取 `.apk`。
  查版本、下载都走 GitHub，不经过学校服务器。
- 两次检查至少隔 60 秒（行尾倒数）；**整次查询 5 秒封顶**，拿不到就提示「无法获取更新」，不重试。
- 有新版：显示版本号、大小、更新说明，点「下载并安装」→ 下到 APP 缓存目录（不用存储权限）→
  校验大小和 SHA-256 → 交给系统安装器覆盖安装。
- 第一次装要在手机设置里允许本 APP「安装未知应用」：APP 直接带老师去那个设置页，返回后自动开始安装，
  已下载的不会重下。
- 交给安装器要 content:// 地址。APP 不依赖 AndroidX，自己写了一个只读的 `ApkProvider`（只认缓存目录
  `updates/` 下的 `.apk`，不导出，靠 Intent 上的临时读权限）。

### 正式签名

5.0.0 是测试签名。从 5.1.0 起用正式签名（`android/wfxx-teacher.jks` + `keystore.properties`，都不进 Git），
**以后每一版都必须用这同一把钥匙签**，系统才允许覆盖安装、APP 内升级才走得通。

从 5.0.0 升到 5.1.0 要先卸载旧版（签名不同，系统不让覆盖），卸载会清掉保存的登录；之后的版本都能在 APP 里直接升级。

### 练习文本挪到「题库」

和网页版教师端一致：「练习文本」页签从「考试」标签移到「题库」标签（题库管理、批量导入、仿真操作题、练习文本）。

## 怎么发一版

见 `android/README.md`「发版」：打正式包，在联网版仓库发一个 tag 为 `teacher-v<版本>` 的 Release，
附件传 apk，**不要标成 Latest**（Latest 留给学生端）。
