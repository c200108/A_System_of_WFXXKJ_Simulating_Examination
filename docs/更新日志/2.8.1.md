# 2.8.1 —— 组卷：按操作题的类别分，不只按知识范围分

发布：2026-09-20　｜　同期：学生桌面端 4.4.0

---

## 一、「互联网原理与创新」不再出网页文件题

这个大题的三道操作题原来是按知识范围抽的：`scopes: ["计算机网络基础"]`。问题是
**这个范围里有两类完全不同的题**：

| | 学生要做什么 | 适合这个大题吗 |
|---|---|---|
| 拖拽类（热区、流程图） | 在图上把元素拖到正确位置 | 是 —— 考的就是原理 |
| 网页文件类 | 在真机上建文件夹、用记事本改 HTML/CSS | 否 —— 那是网页制作 |

题库里这个范围共 12 道操作题，6 道拖拽、6 道网页文件。光靠知识范围分不开，抽到
哪类全看运气。

所以组卷配置多了一个维度 —— **操作题的类别**：

```yaml
- { type: "操作题", count: 3, scopes: ["计算机网络基础"], sim_kinds: ["drag"] }
```

可填 `win`（Windows 操作）、`wps`（WPS 文字）、`html`（网页文件）、`ai`（AI 工具）、
`drag`（拖拽类，也就是没有仿真环境的那些）。留空表示不限，和原来一样。

**类别怎么判定，和出卷、判分那条路完全一致**：先看老师配的仿真任务，没配就按题干
推。所以组卷时筛出来的题，学生在考场上看到的就是那一类，不会出现"卷子上说是网页题、
客户端铺出来却是别的"。

## 二、组卷页不再重复说一遍

原来每一组后面跟一句说明文字，而它说的正是前面那几个标签已经说过的：

```
操作题  Windows系统操作    Windows 操作            ← 后面这句纯属重复
选择题  计算机网络基础  长题干或带图   长题干或带图的选择题
```

现在只留标签，多出来的类别也是一个标签：

```
操作题  计算机网络基础  拖拽 / 热区 / 流程图
```

配置里的 `label` 字段保留但不再显示 —— 已经写了它的 `config.yaml` 仍然能正常加载
（配置对未知字段是报错的，删字段会让老部署起不来）。

题库不够时的提示语原来用的就是这个手写说明，现在改成**从这一组的条件本身拼**：

```
「互联网原理与创新」·计算机网络基础 拖拽题要 5 道，只有 3 道可选
```

手写的说明忘了改就会说反，条件拼出来的不会。

---

## 三、顺带修掉的一处不一致

「预览题量」原来自己抄了一遍筛选条件（题型、知识范围、要不要有答案）。加了类别
这一维之后，抄的那份必然漏 —— **预览说够，真组卷说不够**。现在两边用同一个函数。

这类重复是同一个 BUG 的温床：加一个维度就要记得改两处，而漏改的那一处只在
"数量刚好卡在边界"时才露出来。
