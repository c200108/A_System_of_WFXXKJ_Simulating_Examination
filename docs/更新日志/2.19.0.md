# 服务端 2.19.0 —— 选择判断题乱序；题库列表两行省略、按有无答案筛选

发布：2026-11-05

## 新增

### 组卷设置「选择判断题乱序」

开启后每个学生拿到的卷子，选择题、判断题的先后顺序各不相同，选择题的选项顺序也打乱（答案自动跟随）。

- **不跨大题**：只在同一大题里换（按题型组卷时就是同一题型里换）。同一大题里选择题和选择题换、判断题和判断题换，各占原来的位置，第一大题的选择题不会跑到第四、五大题去。操作题一道都不动；判断题的「正确 / 错误」两个选项不换。
- **每个学生一套、而且固定**：种子是「考试 + 学生」。学生平台和学生端 exe 按学号；公开链接答题（/take/…）取卷时还不知道是谁，按这台浏览器的固定种子 —— 同一个学生刷新、断线重进，看到的还是同一套顺序。
- **判分不受影响**：选项换了位置，屏幕上照旧从 A 排到 D，但交上去的是这个选项**原来的字母**。判分、成绩分析、答案卷、老师看到的答卷都按原字母，和不乱序时一模一样；交卷后「正确答案」显示成学生屏幕上看到的字母。
- 原来单独的「打乱选择题的选项顺序（答案自动跟随）」去掉，并进这个开关，一起开、一起关。

### 题库列表

- 题干、可选项、答案太长时只显示两行，末尾「…」后面有「展开」，点了看全文，再点「收起」。放得下两行的不出现「展开」（按实际显示的高度量，列宽变了重新量）。
- 没有答案的题在答案列标灰色「无答案」。
- 筛选条件新增「有无答案」：有答案 / 无答案（全是空格的算没答案，和组卷「跳过原卷未给答案的题目」同一个口径）。「按当前筛选条件导出」也跟着筛。接口 `GET /api/questions?has_answer=true|false`。

## 变更

- 开了乱序的卷子，组卷预览、存档、导出 Word / Excel / 答题网页里的题序和选项都是**题库原样**（原来选项是在组卷那一步就打乱后存的）；每个学生的乱序在取卷时才做。存档里记一笔 `shuffle`，取卷接口（`/api/take/{token}`、学生平台取卷）和学生端考试包的 `manifest.json` 都带上这个开关。
- 2.19.0 之前组的老卷子不乱序，照原样考；它们当初打乱过的选项照旧有效。
- `config.yaml` 新键 `paper.shuffle_objective`；老配置里的 `paper.shuffle_options` 照样认（读成新开关）。组卷接口新字段 `shuffle_objective`，老版本教师端 APP 传的 `shuffle_options` 也认。

## 要配的客户端

- 学生端 exe 4.14.0 起按乱序显示；老 exe 拿到开了乱序的考试包按原顺序考，判分照样对。
- 教师端 APP 5.1.4 起组卷开关叫「选择判断题乱序」。
