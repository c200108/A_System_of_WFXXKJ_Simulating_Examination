发布：2026-11-25（和学生端 4.17.0 同一期）

## 人工智能通识教育测评题

- 题目来自学校发的《2026年下半年人工智能通识教育测评·七/八年级试题（汇总）》两份 Word，整理成
  `backend/app/services/literacy_bank.json`（334 道：七年级 179、八年级 155；单选 269、多选 33、判断 28、填空 4）。
  题干里的答案括号挖空成「（　　）」；纯分类标签（【选择题】【多选】【思维维度】【考察：…】）去掉，【情境】保留。
- `services/literacy.py`：两个知识范围「人工智能通识教育测评题（七年级）」「（八年级）」，`app.seed` 每次启动补字典
  （排在十类后面，`sync_on_start` 不会停用它们）和题目（按题干哈希查重，删进回收站的不会再冒出来）。
  原卷部分来源记「测评题」，examcoo 补充部分（答案由 AI 推断）记「测评题（补充，答案待核对）」，编号 `T0xxx`。
- 组卷规则（`papers._check_literacy`、`paper.type_pool`、`blueprint.slot_pool`）：
  - 六大题每一组都排除这两个范围；按题型组卷没选测评范围时也排除；
  - 选了测评范围：只能单选一个（和其他范围、和另一个年级都互斥，混选 400）；不能用六大题；
    操作题强制 0；选择题 + 判断题必须正好 40 且选择题多于判断题；填空题随意。
  - 组卷页「按题型」里新增「题目来源」：十类 / 七年级测评 / 八年级测评。选测评时选择题在 24~34 之间随机（🎲 换比例），
    判断题自动补齐 40；操作题输入框锁成 0；六大题的知识范围下拉里看不到测评范围。

## 多选题、填空题（`services/answers.py`）

- 多选：题型仍是「选择题」，答案两个字母以上就是多选。学生交勾中的**原字母**（乱序时显示新字母），比字母集合，全对才得分。
- 填空：答案按「；」分空，可带「第一空：」，括号里（「或」「也可」引出）是也算对的说法；正文里只认「/」分隔
  （「颜色、纹理」是一个答案）。学生交 JSON 数组（一个空时交原文，老客户端只有一个框也认），去空格标点、
  全半角、大小写后比对，按空给分；没设分值的老卷子按全对算答对。
- 取卷多两个字段 `multi`、`blanks`（形状，不是答案）：`exam._item_from_row` 算，学生端各处据此画复选框 / 输入框。
- 作答组件 `frontend/src/components/ObjectiveAnswer.vue`：公开链接答题、学生平台答题、组卷页在线自测共用；
  本地留一份勾选 / 每空内容，连着改不会互相覆盖。组卷页自测的判分在 `frontend/src/answerRules.js`（和服务端同一套）。
- 导出的学生答题网页（离线单文件）同样支持多选复选框、多空填空和按空计分。
- 题库编辑：选择题答案改成勾选（勾两个以上即多选），选项加到 E；填空题答案写法有说明。

## 题库批量操作、停用

- 迁移 0031：`questions.is_disabled`。停用的题还在题库里、能再启用，三处抽题（按题型、六大题、预览）都排除。
- `POST /api/questions/bulk {ids, action, value}`：disable / enable / delete（要删除权限，整批进回收站一条）/
  pin / unpin / scope / difficulty。一次一个事务。
- 题库页：左侧勾选框（翻页保留），勾了出现批量操作条；「在用 / 已停用」筛选；统计多一项「已停用」；多选题标「多选」。

## 网页链接答题核对名单

- `GET /api/take/{token}/classes`：班级下拉（有在用学生的班；考试指定了班级就只列那几个），只给 id 和名字。
- 交卷：不带学号时必须带 `class_id`，姓名在这个班的在用学生名单里才收；对不上 400，提示检查班级姓名或询问老师。
  对上了挂到这位学生名下（记上学号），默认同一人只能交一次。带学号的（学生端 exe）照旧。
- 答题页：班级下拉 + 姓名，去掉学号；交不上时弹窗说明，卷子还在。
