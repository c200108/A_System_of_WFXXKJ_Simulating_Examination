## 一、先修了一个会让整道题失效的误判

```
请打开本题工作目录下的 win06 文件夹……
（1）把“重阳节.doc”文件重命名为“老人节.doc”。
```

这道题被当成了 **WPS 文字题** —— 因为"打开"后面四十个字内出现了 `.doc`。
后果是配了个文档环境，五问一问也判不出来，而**题目照出、文件照铺，表面上
什么毛病都看不出来**。

现在类别判定以**操作动词**为准：出现重命名、改名、"移动/复制到某文件夹"、
删除文件（夹）、新建文件夹，就是文件操作题，哪怕文件名是 .doc。

反过来也堵上了：WPS 题里"把第四段移动到文章末尾"也是"移动"，但后面跟的不是
文件夹 —— 不能因为一个动词就把排版题拖进文件操作那条路。

顺带修掉一个静悄悄的漏判：正则里写的是 `文件?`（"文" + 可选的"件"），本意是
"可选的『文件』两个字"。于是

```
将“新增项目.txt”复制到“冰上项目”文件夹中
```

这种不带"文件"二字的说法**整条不判**。

## 二、文件操作新认的说法

| 题干里的说法 | 生成什么 |
|---|---|
| 把"A.doc"重命名为"B.doc" | 铺出 A.doc；判 B.doc 在、**且 A.doc 不在** |
| 在"X"文件夹中建立一个新的文件夹"Y" | 铺出 X；判 X/Y 是文件夹 |
| 将名为"Z"的文件夹复制到"W"文件夹中 | 铺出 Z（文件夹）和 W；判 W/Z 在 |
| 删除"塔里木盆地"文件夹 | 铺出它；判它不在了 |
| 删除"赛区"文件夹中的图片文件 | **铺一个 `示例图片.jpg` 出来**；判它不在了 |

最后一条是有意的：题干没点名删哪一个，那就生成一个具体的文件 ——
**学生看到的和判分看的是同一个文件**，题目才做得成。

重命名判两头（新名在、旧名不在），只判前一半的话学生复制一份改名也算对。

## 三、WPS 文字题：按原文定位段落

真题几乎都是这么写的：

```
将文章第2自然段（“远处的群山……线上系的花瓣儿。”）字体格式化为
绿色；楷体；斜体；四号字；加双波浪形下划线。
```

括号里那句原文有两个用处：**按内容定位段落**，以及**塞进生成的正文里**
（不塞的话学生翻遍文档也找不到要改的那一段）。

**为什么不按序号定位**：同一道题里往往还有"把某段移到最后"。段落一挪，
按序号写的检查点全指错 —— 学生做对了反而判错。这一条在自检里翻过车，
现在只要题干给了原文就一律按内容找。

新认的格式：

- 页眉、页脚（"为文档添加页眉为'春天'"）
- 纸张大小（A3/A4/A5/B4/B5/16开）
- 成对页边距（"左右页边距为2.5厘米，上下页边距为2厘米"）
- 字体颜色、下划线、加粗、倾斜、"标题"样式
- "文本之前2个字符"这种省掉"缩进"二字的写法
- 把某一段移到文章末尾

颜色比对是**宽松**的：检查点写"红色"，学生在 WPS 里点标准色板的 FF0000 或者
主题色的 C00000 都算对 —— 判错了他会觉得莫名其妙。

### 顺带修了一个白送分的检查点

"文本之前缩进 / 文本之后缩进"写进检查点之后**从来没判过** —— 判分器的循环里
漏了这两个键，于是这一问永远算对。

## 四、生成的文档能带页眉页脚和纸张了

`build_docx()` 原来只写正文和页边距。现在页眉、页脚、纸张规格（A4/B5/A3…）
都写得出、读得回：

```
写 B5 + 页眉“春天” + 页脚“1”  →  学生端读回来：B5 / 春天 / 1
```

不然"把纸张改成 B5"这类题没有起点（文档本来就是 A4，怎么改都对不上），
"把页眉改成 X"也看不到原来的页眉。

## 五、新工具：操作题体检

```bash
python backend/tools/验操作题.py                      # 体检整库
python backend/tools/验操作题.py --xlsx 题库.xlsx      # 体检一份导出
python backend/tools/验操作题.py --xlsx 题库.xlsx -n 7  # 盯着第 7 道看细节
```

它把每道题走一遍**全程**：题干 → 环境 + 检查点 → 铺考场 → 照着检查点做对 →
判分。判不满就说明题目不自洽（环境少铺了东西 / 检查点指向不存在的路径 /
文档表达不了那个格式），而这三种在考场上的表现是一样的：**学生做完了，
分数是零，老师那边什么错都看不到**。
