# 教师端 APP 5.1.4 —— 组卷「选择判断题乱序」

发布：2026-11-05

## 变更

「组卷 → 选项」里的「打乱选择题的选项顺序」换成「选择判断题乱序」：开启后每个学生的选择题、判断题顺序各不相同，选择题的选项也打乱（答案自动跟随）；只在同一大题里换，操作题不动。和网页版组卷是同一个开关。

要配 2.19.0 以上的服务端。APP 同时把新旧两个字段都发给服务端，连老服务端时这个开关照旧只管选项乱序。

## 修复

点「学生 → 班级」闪退回桌面（`java.lang.VerifyError: Verifier rejected class j.e … register v0 has type Undefined`）。
原因是「我的 → 需求反馈」的后台加载写成了 `new Object[3]` 加 `if (admin) r[1] = …`，R8（AGP 8.7.3）把它压成一条 `filled-new-array`，
非管理员那条路上 r[1] 的寄存器没有赋值；R8 又把反馈页、班级页、打字文本的后台任务合并成一个类，安卓校验这个类失败就整个拒绝加载，
于是一点班级页就崩（5.1.3 就有，不挑机型）。改成每个位置先在局部变量里赋好值（含 null）再一次性建数组。

本机 `gradlew :app:compileReleaseJavaWithJavac` 编译通过；没有打 APK，没有在真机上点过。
