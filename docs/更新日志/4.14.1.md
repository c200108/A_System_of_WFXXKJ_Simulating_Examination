# 学生端 4.14.1 —— 教师端地址不带 http://，自动选 https / http

发布：2026-11-05

## 变更

- 登录页「教师端地址」只填地址本身（`192.168.1.8:8000`、`exam.xxx.edu.cn`），不带 http://；去掉「如 192.168.1.8:8080」示例提示。老版本存下来的 `http://…` 打开时自动去掉前缀显示。
- 登录页顶上的说明改成「初始密码是学号，老师重置后是 123456」（配服务端 2.19.1）。

## 新增：自动选协议（`client/api.py` 的 `base()`）

| 填的地址 | 用什么 |
|---|---|
| IP：IPv4、localhost、`[IPv6]`，带不带端口都算 | 直接 http |
| 域名 | 先试 https（`/api/desk/ping`），连不上（含自签证书通不过）再试 http |
| 自己写了 `http://` / `https://` | 照写的走，不猜 |

- 试出来的协议记在本机配置（`server_schemes`），重开程序直接用；记住的协议后来连不上会自动忘掉，下次重新试。两个都不通时 30 秒内不再重试，免得断网时每个请求都白等两轮。
- 登录、班级列表、取考试包、交卷、补传、考试中途问设置、首页、改密码、打字练习——所有请求都走 `base()` 选出来的同一个地址。考试包里记的教师端地址也是选好协议的那个。
- `api.norm()` 现在只整理地址（去空格、去末尾斜杠），不再自己加 http://；选协议在后台线程里做，不卡界面。
- 烤进 exe 的默认地址 `111.170.33.3:3315` 是 IP，照旧走 http。
