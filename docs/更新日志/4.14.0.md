# 学生端 4.14.0 —— 选择判断题乱序

发布：2026-11-05

## 新增

老师组卷时开了「选择判断题乱序」（服务端 2.19.0），学生端按「考试 + 学号」在本机打乱：

- 同一大题里选择题、判断题各自换位置，选择题的选项也换位置；操作题不动，不会跨大题。
- 同一个学生重开程序、断电接着考，看到的还是同一套顺序（草稿按题目记，顺序变不变都恢复得上）。
- 屏幕上选项照旧从 A 排到 D，交上去的是原来的选项字母，判分、成绩分析不受影响。

老考试包（没有 `shuffle`）按原顺序考。老客户端拿到开了乱序的考试包也按原顺序考，判分照样对。

改动：`desktop/client/shuffle.py`（和网页的 `frontend/src/shuffle.js` 同一套规矩）、`client/package.py` 读 `shuffle`、`client/exam_ui.py` 开考时打乱、选项显示新字母交原字母。

## 验证

`desktop/tests/test_shuffle.py`（同学生同顺序、不同学生不同、不跨大题、操作题不动、选项显示新字母交原字母、判断题选项不换）、`test_ui.py::test_选择判断题乱序_按学号打乱_交的是原字母`。本机起学生端截了图（`D:\Pythonproject\WFXXKJ-ui-shots\bank-shuffle\学生端exe-*.png`）。exe 还没有重新打包。
