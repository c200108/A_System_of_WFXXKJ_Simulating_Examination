# 试卷 Word 文档 → 题库

攒了一堆中考卷、模拟卷的 Word 文档，想把里面的题弄进题库，一道道复制粘贴
太慢。这个工具把整个文件夹的试卷一次拆开，生成一个**可以直接上传的 Excel**。

它只认**菁优网导出的那种带【答案】的卷子**（页首写着「参考答案与试题解析」）。
自己排版的卷子认不出来，跑完会明说。

---

## 最省事的办法：拖一下

1. 把要处理的试卷（`.docx`）都放进**同一个文件夹**
2. 把这个**文件夹**拖到 `scripts\试卷转题库.bat` 上面，松手
3. 等十几秒，输出文件夹会自动弹出来

就这三步。跑完在试卷文件夹里多出一个 `题库导入` 文件夹：

```
你的试卷文件夹\
├── 2024年德州市中考信息技术试卷.docx
├── 2025年枣庄市模拟卷.docx
└── 题库导入\                       ← 新出来的
    ├── 题库导入-你的试卷文件夹-123题.xlsx    ← 上传这个
    └── bank-images\                        ← 题目里的图（下面说）
```

最后打开网站 → **题库 → 批量导入 → 选择文件**，把那个 xlsx 传上去。

> 双击 `试卷转题库.bat` 也行，它会让你粘一个文件夹路径进去。

## 或者敲命令

```bash
cd backend
python -m tools.docx_to_bank "D:\试卷文件夹"
```

也可以直接点名几份卷子：

```bash
python -m tools.docx_to_bank 卷一.docx 卷二.docx
```

| 参数 | 作用 |
|---|---|
| `-o 文件夹` | 输出到别处（默认放在试卷旁边） |
| `--no-images` | 不要图片，图片列留空 |
| `--similar 0.9` | 相似度超过多少算重复，默认 `0.95` |

## 上传前请看两列

**知识范围**和**难度**是程序估的，不是抄来的 —— 原卷的考点有几十种
（"Word版面编排""网络应用""机器人与传感器"……），题库只认配置里的十类，
所以要靠题干里的关键词归类。

拿十三份山东卷试过，**和人工逐条核对的结果比，归类一致率 96%**。也就是
一百道里有四五道会归错，比如：

- 「计算机系统由（ ）和软件系统两大部分组成」归成了"计算机软件"，其实考的是硬件
- 「果蔬分拣机识别苹果红绿」归成了"物联网"，也能算"人工智能"

**在 Excel 里扫一眼这两列**，觉得不对就直接改；或者先导进去，之后在题库页面
逐题改也行 —— 改了不影响已经发出去的卷子。

难度是 1~5，按"题型 + 要不要动笔算 + 哪一类知识"估的：判断题打底 2 分，
选择题 3 分，操作题 4 分；要做进制转换、要在脑子里把程序跑一遍的 +2；
一句话就能答的定义题 −1。

## 带图的题

题干里有图的题（程序截图、流程图、系统属性窗口……），图片会被抽出来放进
`bank-images`，Excel 的「图片」列填的是 `/uploads/bank-images/xxx.png`。

所以**导入前要把 `bank-images` 整个文件夹拷到服务器的 `data/uploads/` 下面**：

```bash
scp -r bank-images 用户名@服务器:/opt/A_System_of_WFXXKJ_Simulating_Examination/data/uploads/
```

不拷的话这些题会显示成裂图。**不想要图也行**：把「图片」整列清空，
或者跑的时候加 `--no-images`，题目照样能导入。

有一类题会被整道丢掉：**四个选项分别是四张图**（"下列流程图符号表示正确的是"
那种）。模板一道题只有一个图片列，四张图表达不了，硬导进去学生看到的是四个
空选项。跑完会告诉你丢了几道。

## 它自动做了什么

| 原卷里的样子 | 处理成 |
|---|---|
| `12．（2分）·（2024•山东模拟）题干……` | 题号、分值、出处都去掉 |
| `A．甲　B．乙`（两个选项挤在一行） | 拆成四行 `A.甲` `B.乙` … |
| 判断题：`…只有一个。 √ （判断对错）` | 题干里的答案挖掉，答案列写「正确」 |
| 填空题：`可使用 input 函数` | 题干挖成 `可使用 ＿＿＿＿ 函数`，答案列写 `input` |
| 操作题的【答案】是一长串操作步骤 | 答案列写「略」 |
| 两份卷子出了同一道题 | 只留先出现的那一道 |

**【分析】一个字都不取。** 那是出卷网站自己写的解析，不是题目本身；操作题的
【答案】是"怎么点鼠标"的解说，同理不抄 —— 这类题本来就由老师在
**考试 → 成绩**里人工打分，题干已经把要做的操作一条条列全了。

Python 补全题那种简短答案（`①float ②else`、几行代码）会留着，那是题目本身的答案。

## 跑不动的时候

**「没找到 .docx 文件」**
文件夹里得有 `.docx`。老的 `.doc` 不行，用 WPS 或 Word 另存为 `.docx`。

**「一道题都没拆出来」**
卷子不是菁优网那种版式。这类卷子只能手工填模板：题库 → 批量导入 → 下载模板。

**闪一下就没了 / 提示找不到 python**
说明本机没配好后端环境。先在项目根目录跑一次：

```bash
cd backend
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

**窗口里的中文是乱码**
`scripts\试卷转题库.bat` **必须存成 GBK/ANSI 编码**。cmd 是按当前代码页逐行解析
批处理文件的，存成 UTF-8 的话中文会把命令行本身撑乱。改完这个文件记得另存回 GBK。

**导入时报"知识范围不在允许的范围之内"**
`config.yaml` 里的 `bank.scopes` 被改过，和表里的对不上。工具会优先读
`config.yaml`，所以正常不会出现；真出现了就照着 `config.yaml` 改表里那一列。
